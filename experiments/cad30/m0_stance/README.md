## Два разных вопроса

1. Дискретная математика: допускают ли 218 выборочных состояний геометрические, квазистатические и модельные ограничения? **Да** для пяти протестированных вариантов.
2. Физика: может ли PD через реальные MuJoCo контакты непрерывно пройти всю подготовку и завершить четыре шага? **Нет** для всех пяти испытанных вариантов при 0.3 с на узел и политике минимум трёх реальных опор. Из этого не следует невозможность походки вообще.

При 0.3 с подъём проходит, затем возникает срыв при ML.

### Нюанс про «не отводить корпус назад»

У исходного планировщика PR #43 перед `ML` **жёстко указана целевая продольная координата на −65 мм от сохранённой шестиногой стойки**. Удаление отдельного `four_stance_rebalance` в −30 мм не устраняет эту целевую координату: корпус просто проходит больший путь на фазе `before_ml`. Математическая разница итогового net Y (+20 мм вместо −10 мм относительно сохранённой шестиногой стойки) возникает из-за более дальнего вперёд терминального замыкания, **не из-за доказанного устранения фактического отступления**.

Сама сохранённая стартовая стойка **уже после** ранней Pupper-prebalance (примерно −36 мм относительно первоначального положения), которую нужно учитывать отдельно. Сравнивать положительное смещение от сохранённой позы с продвижением от оригинального старта некорректно.

## Данные о третьем физическом шаге

В отдельном более позднем локальном исследовании ([архив третьего шага в личном Drive](https://drive.google.com/file/d/1f1gSPYVHML_AYGvuEP9twdWZAKTYGU1Q/view)) достигнут `ML→MR→(ML назад ~85 мм)→BL`: задняя левая переносится на +32.1 мм при реальных `Fz`. Однако net COM от сохранённой шестиногой стойки остаётся −67.5 мм, а после BL подъём BR в фиксированной конфигурации требует около 69.2 мм дополнительного переноса COM для геометрического запаса 10 мм. Все испытанные локальные BR-кандидаты нарушают ограничения. Этот факт **не доказывает глобальную невозможность**; он подтверждает необходимость менять всю начальную расстановку и порядок предварительных перестановок, а не лишь величину одного смещения корпуса.

## Воспроизводимость

`stance_sweep.py` **не создаёт нового MPC или походку**: использует существующие `math_first_four_crawl_v1.py` из PR #43 и `dynamic_replay_math_first.py` из PR #44. Ветка должна содержать оба файла через stacked PR; без них возвращается понятная ошибка.

```bash
python -m unittest discover -s experiments/cad30/m0_stance -p 'test_stance_sweep.py' -v

PYTHONPATH="$CAD_ROOT:$REPO" python experiments/cad30/m0_stance/stance_sweep.py \
  --repo-root "$REPO" --cad-root "$CAD_ROOT" \
  --six-state "$PRIVATE/pupper_stance_prebalance_35mm.json" \
  --front-reference "$PRIVATE/pupper_four_bl20_simple.json" \
  --private-output "$PRIVATE/m0_raw" \
  --report "$PRIVATE/m0_compact.json" \
  --variants pr43_baseline no_final_back middle_40 middle_30 outward_10 \
  --physics --node-seconds 0.3
```

`--private-output` содержит полные qpos, Fz, qvel и тяжёлые 2-мс трассы: **не коммитить** в GitHub. GitHub хранит только проверяемый код, тесты и `M0_COMPACT_RESULTS_20261105.json` с SHA-256 трасс. Внешние оригиналы CAD30 — только в личном Drive. Прогоны 5 физических вариантов сделаны локально и независимо от тестов без CAD; 3/3 чистых unit-теста PASS, smoke-проверка двух математических вариантов PASS.

## Следующий физический шаг

Перед подъёмом передних ног убедиться в фактическом Fz задних опор, а перед каждым дальнейшим swing проверить и поддерживать опорную тройку.
