# CAD30 — 60 секунд шестиногой wave-походки (5 ноября 2026)

**Статус:** `FULL_DURATION_MOTION_PASS__STRICT_FIVE_FORCE_SUPPORT_FAIL`.

Это **действительно выполненный** непрерывный физический прогон `mujoco.mj_step` со свободным корпусом на исходной модели Freenove FNK0052 CAD30. Не постановочная анимация и не команда реальному роботу. За 60 с робот продвинулся на **0,378953 м** без падения. Но проект **пока не подтвердил** строго устойчивую пятиопорную походку по всем физическим тактам.

## Фиксированная программа эксперимента

- MuJoCo 3.14.0; оригинальные 30 STL из ранее сохранённого архива владельца, только на Google Drive (два отсутствующих STL заменяются визуальными примитивами, не опорные ноги).
- Масса CAD30-модели ≈1,804868 кг, номинальное трение как в закреплённой сцене; физический шаг **2 мс**.
- Wave: один плановый swing за раз, заданный шаг стопы **20 мм**, подъём **12 мм**, период **3 с**, интерполяция из независимой IK; PD **Kp=7, Kd=0.32** с модельным предельным моментом ±0,7 Н·м.
- Без root teleport, pinning опор, внешнего удержания корпуса или скрытой корректировки исходной физики.
- Истинные контакты и нормальные реакции `Fz` собраны на **каждом** 2-мс шаге, порог «нагружена» — **0,2 Н**. Сводный гистограммный аудит всех 30 000 шагов + 50 Гц временной ряд `Fz`, 25 Гц снимки настоящих `qpos` сохранены в приватном архиве. *Полного массива `Fz`/`qpos` на всех 30 000 шагах архив не содержит*.

| Максимальный момент | 0,37102 Н·м |

| Тактов с 6 / 5 / 4 / 3 / 2 ногами при `Fz ≥ 0,2 Н` | 3092 / 26858 / 47 / 2 / 1 |
| Доля шагов с ≥5 нагруженными ногами | 99,8333% |
| Максимальная непрерывная потеря критерия ≥5 опор | 0,004 с |
| Сатурация модели PD | 0% |

**Ключевое отрицательное условие:** всего **50** из 30 000 тактов имели менее пяти ног с `Fz ≥ 0,2 Н`. В одном 2-мс такте на пороге оставались только **2** ноги. Поэтому утверждение «все время минимум пять нагруженных ног» было бы неверным. Реальный плеер показывает контактные маски на **25 Гц**, и короткие события могут не отображаться; для достоверной оценки обращаться к сводке аудита.

## Воспроизведение и проверка

Исходный источник с `locomotion_cad30.py`, `hexlab/` и `source/mjcf/scene_local30_nominal.xml` — приватный ZIP владельца `FNK0052_CAD30_local_MuJoCo_experiments_2026-11-03.zip` в Google Drive. Оригинальные бинарные CAD не публиковать в GitHub. При установленном `mujoco==3.14.0` и `numpy/scipy`:

```bash
export CAD30_ROOT=/path/to/restored/cadroot
cd "$CAD30_ROOT"
python /path/to/checkout/experiments/cad30/wave60/wave6_60s_experiment.py \
  --seconds 60 --step-mm 20 --lift-mm 12 --period 3

export HEXAPOD_DOCS_ROOT=/path/to/checkout/docs
python /path/to/checkout/experiments/cad30/wave60/export_wave6_viewer.py
python -m unittest discover -s /path/to/checkout/experiments/cad30/wave60 -p 'test_*.py' -v
```

Ветки и просмотр: **PR #24**, `feature/android-local-offline-viewer-20261104`, `/hexapod/wave-60/`, каталог `docs/hexapod/library.json` revision 7. Для локального Termux-плеера — открыть заголовок симуляции и нажать «Обновить библиотеку»; загружаются новые файлы после проверки SHA-256.

Модельные значения момента/массы/трения не калиброваны с реальным Freenove. Следующий научный gate: контроллер с обратной связью, который сохраняет фактически нагруженные 5 опор на каждом 2-мс такте в разных условиях, а не просто подбирает очередную красивую траекторию.
