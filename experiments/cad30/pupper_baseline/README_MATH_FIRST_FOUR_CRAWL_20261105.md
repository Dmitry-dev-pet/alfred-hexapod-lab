# Математический кандидат простейшей четырёхногой походки CAD30 (5 ноября 2026)

**Статус: SAMPLED_GEOMETRIC_STATIC_CANDIDATE. НЕ физическая походка.** Продолжаем от известного источника PR #40 и Issue #38, не от самописного MPC. Никаких команд роботу, смещений корня в MuJoCo `mj_step` и подмены физических кадров.

## Найденная конфигурация

Старт: сохранённая физическая **шестиногая** стойка `pupper_stance_prebalance_35mm.json` из приватного архива PR #40. Модель Freenove FNK0052 CAD30: 30 оригинальных STL (только Google Drive, НЕ в этом ZIP/GitHub), MuJoCo 3.14.0, масса ≈1,805 кг. Принятые **исследовательские**, не паспортные пределы: `|q| <= 1.7 рад`, `|τ| <= 0.7 Н·м`, `μ = 1.1`, `Fz >= 0.2 Н`, минимум статического запаса устойчивости 5 мм. Цель — медленная квазистатическая походка с минимум тремя несущими ногами.

Предварительная перестановка стоп при поддержке передней пары: задние `bl/br` вперед на **80 мм** и наружу на **20 мм**; средние `ml/mr` внутрь на **50 мм**. Затем обе передние ноги поднимаются; корпус отходит назад на 30 мм, сохраняя контакт остальных четырёх. Дальше цикл `ml→mr→bl→br`, шаг каждой стопы **+20 мм в мировой оси Y**, вертикальная дуга 12 мм, с перераспределением веса между шагами. В конце корпус сдвигается в положение, геометрически эквивалентное начальному +20 мм Y.

## Исполненная математика

`math_first_four_crawl_v1.py` применяет исходный `hexlab.stand_geometry_v04` (CAD tibia tip), полный MuJoCo forward kinematics, ограниченную IK через SciPy, проверку COM относительно многоугольника оставшихся опор и линейную статическую задачу контактных сил `M qdd + h = Sᵀτ + Jᵀf` при **qdd=0**. Контакт моделируется точкой у дальнего CAD-вертекса tibia, конус трения — вписанная ромбическая аппроксимация. Отдельная вспомогательная переменная минимизирует самый большой абсолютный момент сервопривода; это устраняет артефакт вырожденного LP, где несущественно выбирались моменты ±0.7 Н·м.

**Итог: 218 дискретных конфигураций (включая подготовку, передние ноги, четыре шага, замыкание), 0 геометрических/статических отказов.** Минимальный запас устойчивости **7.828 мм**, максимальная невязка цели IK **0.000107 мм**, максимальный |q| **1.67025 рад**, пиковый минимально необходимый для равновесия статический момент **0.41174 Н·м** (исследовательский предел 0.7), минимальный положительный зазор tibia в промежуточных swing **2.11 мм**. Самоколлизий и непредусмотренных контактов корпус-пол в проверенных позициях `mj_forward` не обнаружено. Из 218 положений статическая LP также прошла при μ=0.8, 0.6, 0.3, но это не подтверждает динамику или реальное трение.

## Важные ограничения

- Нет **физического** прогона `mj_step` из исходной шестиногой стойки через подготовку и полный цикл; пока только виртуальные состояния, удержание контактов и силовые равновесия. В динамической модели контроллер может не успеть следовать траектории или потерять нагрузку.
- 218 точек — конечная дискретизация, а не математическое доказательство непрерывной траектории или глобальной устойчивости; зазоры между узлами надо проверить.
- Модельные `μ`, массы и пределы сервоприводов не калиброваны. Математическая нормальная сила — не измеренная MuJoCo контактная сила.
- 80 мм перестановки задних стоп — **подготовка**, она ещё не выполнена физически. Выполненный 20-мм математический цикл **не даёт положительного смещения от исходной шестиногой стойки**: дополнительная подготовка корпуса −30 мм, один цикл +20 мм = −10 мм относительно уже смещённой на −36 мм стойки. Для положительного итогового продвижения от самой исходной стойки нужны примерно четыре цикла и физически подтверждённая подготовка.
- Отсутствие необнаруженных контактов в геометрической проверке не заменяет контактные силы и коллизии реальной динамики.

## Повторение

Нужны Python 3.13, MuJoCo 3.14, NumPy/SciPy, приватный исходный CAD30-каталог с `source/mjcf/scene_local30_nominal.xml`, оригинальные 30 STL и `hexlab/stand_geometry_v04.py` (см. [Freenove-CAD-source на Drive](https://drive.google.com/drive/folders/1uPhhIjZApoDhjp2YEUPIc7osXoYYyfk_)). Исходные 2 JSON с физически сохранёнными позами находятся в [архиве PR #40](https://drive.google.com/file/d/1wx8j9HSrGwRLigg2rWCWPOyJZyFifHTn/view?usp=drivesdk).

```bash
export PYTHONPATH=/path/to/CAD30-root
python math_first_four_crawl_v1.py \
  --cad-root /path/to/CAD30-root \
  --six-state /path/to/pupper_stance_prebalance_35mm.json \
  --front-reference /path/to/pupper_four_bl20_simple.json \
  --out math_first_four_crawl_result.json \
  --trace-out math_first_four_crawl_trace.json
python -m unittest test_math_first_four_crawl_v1.py -v  # trace-test SKIP, если нет 218-node JSON рядом
```
