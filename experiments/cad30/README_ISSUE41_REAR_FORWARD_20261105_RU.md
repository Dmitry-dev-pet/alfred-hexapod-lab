# Issue #41 — проверка первого поступательного переноса задних ног Freenove CAD30

**Дата:** 2026-11-05. **Статус:** `PARTIAL_REAR_PAIR_FORWARD_STEP_LT20MM` (при μ=1,1). Это **не** полноценная походка, не автономный MPC и не программное управление настоящим роботом.

Связи: математический план на полный 4-шаговый цикл [#26](https://github.com/Dmitry-dev-pet/alfred-hexapod-lab/issues/26); [Issue #41](https://github.com/Dmitry-dev-pet/alfred-hexapod-lab/issues/41); исходный проверенный 4→2→4 контроллер [draft PR #39](https://github.com/Dmitry-dev-pet/alfred-hexapod-lab/pull/39). Старт — **сохранённая физическая CAD30 поза B** после корректирующей ребалансировки [PR #34](https://github.com/Dmitry-dev-pet/alfred-hexapod-lab/pull/34), а не вымышленная стойка.

## Исследовательский вопрос

Могут ли две задние ноги Freenove FNK0052 (`bl`/`br`) **одновременно** оторваться, перенестись вперёд **именно в воздухе**, приземлиться в новых точках и снова нести нагрузку, пока средние `ml`/`mr` обеспечивают динамическую опору? И выполняется ли требование полезного продвижения центра масс ≥20 мм?

## Метод — чем отличается от PR #39

1. В *дофизическом* планировщике Mink проверяется будущая конечная **четырёхопорная стойка**: предполагаемый перенос двух задних контактов +5/+10/+20 мм по мировой оси Y, фиксация средних стоп и пробное смещение корпуса +6 мм. На узле проверяются IK-ошибка, ограничение ±1,7 рад, статический контактный силовой LP с трением и моментами, запас опорного многоугольника ≥5 мм. Это **не доказательство непрерывной физической осуществимости**.
2. В независимой настоящей MuJoCo 3.14 свободнокорпусной динамике сохраняется исходная подготовка PR #39: шесть малых команд по 2 мм с удержанием четырёх стоп, обычный позиционный PD; исходный путь ранее имел непродемонстрированные гарантии по исследовательским лимитам — не считать всю историю безопасной для железа.
3. Во время ручной гипотезы контактов `ml/mr` каждые 10 мс решается мгновенная **QP полной динамики** `M(q)q̈ + h = Sᵀτ + Jᵀf`. К существующим ограниченным QP ускорениям/моментам добавлена мягкая квадратичная цель на **мировое ускорение Y двух задних стоп**. Цель не означает фактическое движение; фактические позиции и реакции наблюдаются отдельно физикой каждые **2 мс**.
4. Перед возвращением управление переключается на плавный PD до *заранее математически проверенной* конечной стойки (новые цели задних стоп). Мягкая **физическая** защитная коррекция момента у приближающихся к ±1,7 рад суставов (при |q|>1,63 рад) удерживает угол без телепортации qpos и без повышения предела момента. Она реализована только на фазах PD возврата и финального удержания.
5. Эксперимент **не** оптимизирует автоматически контактный график, время переключения, следующий цикл или terminal viability за конечным удержанием. В качестве первой детерминированной точки выбрана малая цель 10 мм; исходную цель +20 мм по COM **не снижать** для итоговой приёмки полноценного шага.

Параметры выбранной экспериментальной точки: цель rear XY +10 мм; Mink terminal body target +6 мм; QP 0,02 с, soft rear Y acceleration =4,5 м/с², вес soft objective 20; PD touchdown ramp 0,24 с; final hold 0,70 с; soft-limit stiffness 5 (Н·м/рад), threshold 1,63 рад; номинальное трение μ=1,1; моделируемый предел |τ|≤0,7 Н·м, research joint ±1,7 рад; масса модели около 1,805 кг. Все эти ограничения **предполагаемые**, не откалиброванные на физическом Freenove.

Критерий истинного полёта задней пары использует одновременно: 
`Fz(bl),Fz(br)<0,08 Н`, **нулевые** MuJoCo floor-пары обеих tibia, `Fz(ml),Fz(mr)>0,08 Н`, просвет каждого заднего маркера ≥2 мм от начала. Поступательный шаг дополнительно требует **фактического смещения Y во время этого полёта**, а не просто движения на земле, как в отбракованных ранних тестах. Строки 
`physics_steps_2ms` и `qpos_samples_20ms` — наблюдения, не заданная командная анимация. Наивный перенос до цели без ограничения суставов приводил к превышению 1,7 рад; он не засчитан.

Конечный G2 предрасчёт для +10 мм / +6 мм: максимальная IK-ошибка ~0,0025 мм, margin ~10,35 мм, оценка необходимой доли модельного моторного лимита ~59,63%; проверяется **отдельно** от результатов MuJoCo.

## Контрольные отрицательные варианты и критерии честного отказа

| Условие | Результат |
|---|---|
| Старый базовый QP, без переноса | Воспроизводится двухопорная фаза 0,238 с и возврат на 4 опоры, но нет forward-step. |
| Цель rear +5 мм | Оба задних контакта реально переместились ~4,6 мм, но условный целевой запас **≥5 мм не достигнут**: `RESEARCH_GATE_FAILED`; это не отрицание положительного физического смещения. |
| μ=0,8, цель rear +10 мм | Наблюдалось шесть физических 2-мс кадров с менее чем двумя несущими опорами; `RESEARCH_GATE_FAILED`. |
| μ=0,6 и μ=0,3, та же программа | QP-невыполнимость, потеря требуемых опор/превышение сырых команд. Результаты считать **неудачными**, даже если COM численно ушёл вперёд. |
| rear +20 мм, torso target +6 мм | Mink terminal G2 preflight **не прошёл**; физический прогон не выполнялся. Это не глобальная невозможность 20-мм шага при другой геометрии. |

Один номинальный детерминированный робот и один выбранный набор параметров, после предварительного поиска: **нет независимого holdout** и нет гарантии устойчивости к ошибкам калибровки. В частности, финальная Fz одной из задних ног лишь около 0,225 Н — запас от исследовательского порога 0,2 Н небольшой. Ни реальный робот, ни реальные сервоприводы не испытывались.

## Код и воспроизведение

Продолжает исходный код без самостоятельной второй реализации QP: 
- `experiments/cad30/dynamic_support_qp.py` — совместимый QP с *опциональной* мягкой целью swing-Y, по умолчанию прежняя математика.
- `experiments/cad30/two_support_transfer.py` — совместимое продолжение исходного физического прогона, terminal preflight и soft torque-limit при физической PD-фазе; при отсутствии новых опций воспроизводит PR #39.
- `scripts/run_issue41_forward_step.py` — фиксированный повтор базового эксперимента, 5/10 мм и трёх отрицательных фрикционных проб + запрет 20 мм, с полным регистрационным журналом и SHA256.
- `tests/test_forward_rear_pair.py` — **5/5 новых реальных model integration tests PASS**; оригинальные **5/5** тестов PR #39 тоже повторно PASS.
- `results/issue41_forward_step_compact_20261105.json` — краткая сводка всех попыток, версии библиотек, хеш исходного XML и сохранённой pose B.

```bash
export CAD30_MODEL_XML=/absolute/path/to/scene_local30_nominal.xml
export CAD30_SAFE_STATE=/absolute/path/to/cad30_safe_pose_B_nominal.json
export PYTHONPATH=experiments/cad30
python scripts/run_issue41_forward_step.py --model "$CAD30_MODEL_XML" \
  --state "$CAD30_SAFE_STATE" --output-dir /tmp/issue41-recordings
python -m unittest discover -s tests -p 'test_forward_rear_pair.py' -v
```

Пакеты MuJoCo 3.14.0, Mink 1.4.0, DAQP 0.11.0, qpsolvers 4.13.0 доступны из проверенного офлайн-архива на личном Drive. **GitHub Actions и Mac не вычисляют физику**.

## Следующий путь к настоящей походке

Нужны совместная оптимизация lift → swing → touchdown → *следующее* движение и **≥20 мм net COM** без насыщения, затем перенос средних стоп и проверка повторяемого цикла. Сейчас принято только `PARTIAL_REAR_PAIR_FORWARD_STEP_LT20MM`: одна реальная перестановка **пары задних ног**, но не полный цикл четырёх ходовых и не автономный алгоритм выбора походки.
