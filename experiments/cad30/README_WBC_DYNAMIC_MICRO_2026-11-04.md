# CAD30 — динамическая перестройка стойки и микро-коррекции WBC (4 ноября 2026)

**Статус: частичный успех только в номинальной MuJoCo-модели, НЕ четырёхногая ходьба, НЕ полный MPC/WBC, НЕ сертификация реального Freenove.**

Связанные задачи: Issue #26 (math-first MPC), Issue #21 (четырёхногая ходьба), draft PR #29 (проверка реальных якобианов позы B). Эта ветка основана на PR #29 и не меняет main.

## Исходное состояние и допущения

- Исходник: физически ранее интегрированная поза B (semi_tucked, t=9.3 s) из Google Drive; 4 опоры ml/mr/bl/br, передние fl/fr подняты.
- Модель CAD30 FNK0052, 30 оригинальных STL остаются только в приватном архиве Drive; MuJoCo 3.14.0, 20 актуаторов (18 ног), масса 1.8048682 кг, шаг dt=0.002 s.
- Один номинальный коэффициент трения μ=1.1, сравнительные отрицательные прогоны μ=0.6 и 0.3. Управление PD Kp=7, Kd=0.32 с условным ограничением моментов ±0.7 Н·м на 18 суставах ног.
- Суставные диапазоны XML ±π рад НЕ совпадают с реальными паспортными пределами. Использованный критерий |q|≤1.7 рад — только исследовательская граница.
- Начальная поза B имеет проблемные углы ±1.7084 рад, а после короткой стабилизации примерно ±1.715 рад. Значит весь переход *с самого начала* не удовлетворяет строгому |q|≤1.7. Его нельзя переносить на реальный робот как готовую безопасную последовательность.

## Что реально вычислено

Выполнена перестройка B → новая стойка с одновременным изменением суставов всех четырёх опор и малой компенсирующей коррекцией корпуса. Оптимизация SLSQP использует фактические контактные точки и якобианы из mj_jac; поиск ограничивает углы суставов целью ±1.66 рад, а точки опорных ног удерживает в линейном приближении. Далее двигатели с PD-командами и реальными контактами исполняют 1.5-секундный плавный переход через mj_step. В конце 0.8-секундная выдержка.

Конец перестройки (t≈3.1 s): max |q|=1.663414 рад, геометрический запас COM четырёх опор ≈16.6168 мм. Вплоть до этого момента физика прошла без потери четырёх несущих ног при μ=1.1 (но исходный участок выходит за экспериментальный предел углов).

Следом проведено **три микро-коррекции**: всякий раз управляющий модуль заново использует текущие qpos и фактические контакты, квазистатический LP проверяет баланс сил и моментов (32-гранное вписанное приближение конуса трения, Fz каждой активной ноги не меньше 0.2 Н, предполагаемая нагрузка привода не больше 90% модельного предела). Только если проходит, WBC линеаризует удержание четырёх стоп и выдаёт малые совместные изменения суставов под запрос +0.35 мм корпуса по +Y. Каждая коррекция — 0.3 с плавной подачи, затем 0.35 с выдержки. После каждой фазы следующее решение пересчитывается по наблюдаемым контактам.

**Важный исправленный сбой:** первоначальный вариант на границе каждой фазы заменял накопленный motor target измеренным q, создавая скачок команды и нежелательное движение корпуса на ~10.68 мм, с уменьшением запаса до ~6 мм. Исправление сохраняет прошлую моторную цель и **прибавляет небольшую рассчитанную коррекцию**; итоговый физический ответ существенно спокойнее. Результат контролируется по физике, а не по линии на графике.

Контактный центроид — лишь приближённый индикатор движения поверхности контакта, он может изменяться без скольжения твёрдого тела. Эти значения не доказывают нулевой slip. Дополнительные ~0.84 мм — эффект управления относительно дрейфа контрольной стойки, а **не ходьба**. Фазы различаются по приложенным командам, иначе условия одинаковы.

## Проверки на менее высоком трении — отрицательные

При μ=0.6 и μ=0.3 исходная поза уже испытывает кратковременную потерю контакта (в некоторых шагах до нуля из четырёх реально нагруженных ног). Безопасный контроллер **не выдал ни одной микро-команды**. При μ=0.6 силовая LP-проверка была выполнена и не нашла допустимого статического решения в заданных ограничениях; при μ=0.3 микро-планировщик остановлен проверкой измеренной позы до вызова LP. Это разные причины отказа, и обе сохранены.

Из корня локально восстановленного CAD30:

~~~bash
export CAD30_MODEL_XML="$PWD/source/mjcf/scene_local30_nominal.xml"
export CAD30_REPLAY_ZIP="/path/to/FNK0052_claw_tuck_ABC_2026-11-04_v2_no_CAD.zip"
PYTHONPATH=experiments/cad30 python experiments/cad30/cad30_dynamic_v2.py \
  --model "$CAD30_MODEL_XML" --replay-zip "$CAD30_REPLAY_ZIP" --target 1.66 \
  --micro-count 3 --mu 1.1 --out results/local_cad30_micro.json
PYTHONPATH=experiments/cad30 python -m unittest -v test_cad30_dynamic_v2
~~~

Тесты при отсутствии исходных приватных моделей должны быть пропущены, а не считаться успешными.
