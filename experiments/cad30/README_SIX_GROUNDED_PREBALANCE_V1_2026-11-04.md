# FNK0052 CAD30 — математическая подготовка четырёхопорной стойки, начиная с шести ног

**Статус: положительный подготовительный эксперимент при μ=1.1, НЕ четырёхногая ходьба и НЕ реальные испытания Freenove.**

## Задача

По уточнению владельца проекта сначала **все шесть стоп на земле**. Не поднимать передние «клешни», пока не найдена физически достижимая конфигурация для четырёх оставшихся опор. Сначала перенос центра масс, затем разгрузка передних и только затем их подъём. Без автономного выбора очередности шагов, нейронной координации или рендеринга MP4.

## Математическая модель

Пусть `P4 = convex_hull(p_ml, p_bl, p_br, p_mr)` — многоугольник четырёх будущих опор, а `c_xy` — проекция общего центра масс. Геометрический запас `margin(c_xy, P4)` — минимальное подписанное расстояние до его рёбер. Для прямоугольных/трапециевидных опор без динамики идеальная точка максимального запаса не обязана быть достижима суставами. Поэтому выбираем **достижимый** целевой перенос корпуса с реальными ограничениями IK, сцепления и моментов двигателей, а после проверяем всю траекторию динамически, а не только конечный кадр.

Из исходной физически стабилизированной шестиногой позы: COM ≈ `(0.00012, +0.00803) м`, проекция лежит на ~8 мм **вне** полигона будущих четырёх опор. Для статического запаса 16 мм достаточно перемещения COM примерно на 24 мм назад; геометрический максимум ~98 мм запаса требует ~106 мм перемещения COM и не является практически осуществимым требованием. В существующем CAD30 сценарии локальная IK-проверка ограничивает доступный сдвиг целевых точек опор примерно 44 мм. Поэтому геометрический максимум **не** принимаем за физический оптимум.

Физическая проверка кандидатов выполняется через Python 3.13.5 / MuJoCo 3.14.0 на исходной модели CAD30 (30 исходных STL только из приватного источника, в PR их нет). Внутреннее сканирование цели в миллиметрах (опорные цели, не абсолютное смещение COM) включает 28.25, 32.13, 36.01, 38.00, 39.75, 40.00, 42.00 и 43.76 мм. Отбор консервативный: оставшиеся четыре ноги **все** продолжают касаться пола на каждом 2-мс шаге, ограничения моментов не насыщаются, две передние перестают быть опорными, затем поднимаются как клешни.

## Шесть опор → четыре: фиксированная последовательность, μ=1.1

1. Инициализация через `static_pose` + 1 s `hold_under_gravity`: все шесть ног реально касаются плоскости.
2. 2 s плавного переноса корпуса командой смещения опорных IK-целей +38 мм по CAD +Y. Передние ноги пока остаются на полу.
3. 0.6 s стабилизации после переноса; COM в наблюдаемой физике ≈ `(0.00012, −0.02050) м`.
4. 1.5 s мягкой разгрузки передних стоп: маленькая, плавно меняющаяся команда высоты +10 мм. Фактическая суммарная нормальная сила передних контактов снижается с **~3.57 Н до 0**; обе ноги перестают касаться пола. Это **управление положением**, НЕ непосредственная команда силы.
5. 0.7 s выдержки. Проверяем четыре несущие ноги на земле и положительный запас устойчивости.
6. 1.5 s продолжающегося подъёма обеих клешней, 0.5 s выдержки; реальный просвет голеней около **98.7 мм**.

**Результат:** 6.8 s динамики после исходной 1-секундной стабилизации; минимум 4 контакта со стойкой **на каждом физическом шаге** (`dt=0.002 s`), в последней фазе только `ml/bl/br/mr`, минимальный крайний геометрический запас по текущей четырёхопорной стойке в конце **23.56 мм**, модельный пик командуемого момента **0.476 Н·м** (условный предел 0.7), доля насыщения 0. Задняя/средняя несущие ноги **НЕ шагают**, поступательной ходьбы нет.

При командных сдвигах 40 / 42 / 43.76 мм конечный геометрический запас больше, но **в процессе переноса** некоторые несущие ноги кратковременно теряют контакт (минимум 3 / 2 / 2 контакта среди четырёх). Поэтому больший конечный запас ≠ лучший безопасный переход. Ближе к порогу ~39.75 мм сохраняются все четыре опоры именно в этом детерминированном тесте, но 38 мм оставляет инженерный резерв; это **выбранный лучший из ограниченной проверенной сетки**, а не доказанный глобальный оптимум.

## Отрицательные условия

Та же команда переноса и разгрузки при расчётном трении μ=0.6 приводит к временному числу несущих опор 1, при μ=0.3 — 0, также наблюдается модельное насыщение моментов. **Поэтому не заявляется устойчивость на скользком полу.** Масса ~1.805 кг, инерция, трение и лимит серводвигателей не калиброваны по физическому комплекту.

## Артефакты и проверки

- `experiments/cad30/six_grounded_prebalance_v1.py` — чисто расчётное управление четырёхопорной подготовкой и запись динамики.
- `experiments/cad30/test_six_grounded_prebalance_v1.py` — пять регрессионных тестов; MuJoCo и оригинальные локальные CAD-детали нужны для физического запуска.
- `results/six_grounded_prebalance_compact_2026-11-04.json` — суммарные положительные и отрицательные проверки, SHA256 полного источника.
- `scripts/export_six_grounded_prebalance.py` — **только** трансляция реальных записанных `qpos` через `mj_forward` в координаты Three.js, без нового физического расчёта или видеорендера.
- `docs/hexapod/six-to-four/` — 3D replay реальной 6.8-секундной записи, camera orbit/seek/contacts/forces.
- Полные исходные qpos/50Hz сила контакта и контрольные SHA-256 хранятся в Google Drive; в GitHub оставлены код и текст/JSON каталога.

Команда для восстановления со смонтированной приватной CAD30-моделью:

```sh
python experiments/cad30/six_grounded_prebalance_v1.py --mu 1.1 --shift-mm 38 --front-unload-mm 10 --record --out results/six_grounded_claws_mu1p1_2026-11-04.json
python -m unittest experiments/cad30/test_six_grounded_prebalance_v1.py -v
python scripts/export_six_grounded_prebalance.py
```

Нельзя считать успешный подъём обеих клешней доказательством циклической четырёхногой походки.
