# CAD30: достаточное условие периодической **геометрической** походки

Дата: 5 ноября 2026. Основная задача: [Issue #50](https://github.com/Dmitry-dev-pet/alfred-hexapod-lab/issues/50). Продолжение математического протокола PR #53 и отрицательного ограниченного поиска PR #55.

**Статус: доказана конструктивная лемма только для двумерной опорной геометрии; физическая периодическая походка CAD30 НЕ доказана.** Не добавлять очередной контроллер отдельной ноги. Тесты проверяют *математическую конструкцию*, а не работу сервоприводов.

## Лемма 1. Построение полного периода на плоскости

Пусть четыре точечные стопы \(p_1,\ldots,p_4\) лежат на одной горизонтальной плоскости и образуют невырожденный выпуклый четырёхугольник. \(c_0\) — проекция центра масс на плоскость. Выберем положительный запас устойчивости \(\rho>0\), величину шага \(\delta=(0,\Delta),\Delta>0\), и произвольный порядок четырёх ног \(\pi\).

Через \(P^{(k)}\) обозначим четыре точки опоры после того, как первые \(k\) ног порядка \(\pi\) перенесены на \(\delta\). Перед очередным переносом нога \(\pi(k)\) снята с опоры и три остальные образуют треугольник

\[
T_k=\operatorname{conv}\big(P^{(k-1)}\setminus\{p_{\pi(k)}^{(k-1)}\}\big).
\]

Для выпуклого многоугольника \(A\) определим **внутреннюю безопасную область**

\[
E_\rho(A)=\{x\in A:\operatorname{dist}(x,\partial A)\ge\rho\}.
\]

**Достаточные условия для *геометрического* периода:**

1. \(c_0\in E_\rho(\operatorname{conv}P^{(0)})\).
2. \(E_\rho(T_k)\ne\varnothing\) для каждого из четырёх переносов.
3. После каждого переноса новая четвёрка стоп образует невырожденную опорную область.

**Тогда** существует непрерывная траектория проекции центра масс \(c(t)\) с запасом ≥ \(\rho\) в каждом действующем опорном многоугольнике, в которой последовательно переносится каждая стопа на \(\delta\), и граничные условия \(c(T)=c_0+\delta,\ p_i(T)=p_i(0)+\delta\) выполняются точно.

**Конструктивное доказательство.** Выбираем \(c_k\in E_\rho(T_k)\). Перед переносом \(k\) при всех четырёх опорах движем COM по отрезку от предыдущего \(c_{k-1}\) к \(c_k\). Обе точки принадлежат \(E_\rho(\operatorname{conv}P^{(k-1)})\), которая выпукла: все точки отрезка тоже в ней. Фиксируем COM в \(c_k\), отрываем и переставляем ногу \(\pi(k)\) на \(\delta\); остальные три стопы неизменны, так что COM остаётся внутри \(T_k\) с запасом. После приземления четыре опоры снова доступны. В конце все стопы перенесены на одинаковое \(\delta\); целевая точка \(c_0+\delta\) лежит внутри финальной области с тем же начальным запасом. Последний отрезок замыкает период. □

Это **не требует численного решения нелинейной динамики**. Расчётные точки можно находить по пересечению сдвинутых внутрь полуплоскостей и проекции на выпуклый многоугольник (скрипт ниже).

### Почему лемма не доказывает походку Freenove

В лемме проекция COM перемещается *произвольно*: она не учитывает, сможет ли робот с заданными 18 суставами, длинами ног и формой корпуса туда попасть. Не проверены IK, вырожденность якобианов, угол и момент каждого привода, статические реакции, контактное трение, высота отрыва, столкновения, изменения ориентации, обратная связь и динамическая устойчивость.

## Лемма 2. Условие для **физической квазистатической** модели

К лемме 1 необходимо добавить проверяемые **на всех отрезках, а не только в узлах** условия:

- Существует непрерывное семейство конфигураций \(q(t)\), реализующих выбранную траекторию COM и закреплённых стоп при фазе опоры, а во время swing — положительный клиренс свободной стопы. Все суставы лежат строго внутри допустимого интервала, нет столкновений и недостижимых точек.
- Для каждого времени найдены силы контактов только на реально опирающихся стопах и моторные моменты, удовлетворяющие статическому балансу \(J(q)^Tf+S\tau=h(q,0)\), неотрицательным нормальным силам, конусам трения и предельным моментам **с положительным резервом**. Свободная нога не несёт нагрузку; перед очередным отрывом нагрузка на требуемой тройке действительно устанавливается.
- Начальная и конечная **полная конфигурация** корпуса и суставов совпадают с точностью до поступательного смещения \(\delta\); начальные/конечные скорости нулевые или одинаковые. Подготовка из шести опор должна быть отдельно достижима; её отрицательное смещение должно входить в общий баланс.

**При выполнении всех этих условий** получаем квазистатически реализуемый период для идеализированной модели. Реальный конечный темп и позиционные PWM-приводы по-прежнему требуют отдельной динамической/замкнутой проверки MuJoCo. Сам факт существования подходящих сил не означает, что PD-сервоприводы создадут их автоматически.

Для перехода от конечной сетки к непрерывной гарантии понадобятся доказанные ограничения изменения функций ограничений между узлами (например, интервальные или Lipschitz-оценки) либо другой строго обоснованный метод проверки траектории. Обычные 218 «успешных» дискретных кадров такой гарантии не дают.

## Применение к нашему CAD30, **только фиксированный footprint**

Вход: подлинный численный снимок `pupper_four_bl20_simple.json` из архивного физического опыта PR #40. SHA256 файла закреплён в `recorded_4foot_fixture.json`. Эти координаты **получены физическим моделированием**, но математический путь ниже не исполнялся в MuJoCo.

В сохранённой позе проекция COM равна **(−0,038; −21,050) мм**, пересечение диагоналей четырёхугольника около **(−12,645; −117,601) мм**. Смещение COM от пересечения диагоналей ≈ **97,37 мм** — почти полностью вперёд относительно четырёхопорного footprint.

При неизменных других стопах для одного подъёма и \(\rho=10\) мм необходимо перенести COM как минимум:

| Отрываемая нога | Минимальное смещение COM |
| --- | ---: |
| `ml` | **92,09 мм** |
| `mr` | **101,46 мм** |
| `bl` | 0 мм |
| `br` | 0 мм |

Это строгая *необходимая двумерная нижняя граница* только для конкретных фиксированных точек стоп и положений COM; она **не** ограничивает схемы, где опоры сначала переставляют.

Для шага каждой из четырёх стоп на `+20 мм Y`, гарантированного **геометрического** запаса 10 мм и указанного исходного footprint найдены свидетельства для **24/24 порядков**. Наш алгоритм выбирает в каждый момент ближайшую точку безопасного треугольника к исходному COM с учётом постепенной трансляции. *Лучший среди этих 24 конструктивных вариантов*, а **не доказанный глобальный оптимум**:

- порядок `bl → br → ml → mr`;
- суммарный путь COM по четырёхопорным фазам ≈ **273,21 мм** за чистый период `+20 мм`;
- один из переносов COM достигает **101,49 мм**;
- минимальный запас в трёхопорных фазах **10 мм**; четырёхопорные соединительные отрезки имеют запас ≥ **16,54 мм**.

**Следствие для проекта:** наша серия 1728/1728 «положительных» двумерных проверок в PR #55 не означает, что 1728 роботных походок возможны. Из этих данных видно, почему проект застрял: допустимые траектории COM на плоскости существуют, но для конкретного расположения массы и четырёх стоп они требуют очень больших перемещений тела. Следующий информативный математический тест — **оценить достижимое множество COM CAD30 при фиксированных трёх опорах и пределах \(|q|\le1{,}7\) рад, \(|\tau|\le0{,}7\) Н·м**. Если его пересечение с безопасным треугольником пусто, есть сертификат невозможности *этого шага из этой расстановки*, а не всего проекта.
