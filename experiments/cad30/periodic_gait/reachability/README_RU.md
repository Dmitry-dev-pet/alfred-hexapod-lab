# CAD30 — достижимость центра масс при четырёх/трёх закреплённых стопах

**Дата:** 5 ноября 2026 года. **Основная задача:** [alfred-hexapod-lab #50](https://github.com/Dmitry-dev-pet/alfred-hexapod-lab/issues/50). Дополнение к [плоской лемме PR #56](https://github.com/Dmitry-dev-pet/alfred-hexapod-lab/pull/56).  
**Итог:** `BOUNDED_SCREEN_ONLY_NOT_CERTIFIED_REGION`. Это НЕ доказательство невозможности ходьбы, НЕ подтверждение достижения промежуточных состояний и НЕ физический прогон MuJoCo.

## Данные и модель

Измеренное физическое состояние Freenove FNK0052 CAD30 **после одного заднего шага BL** из эксперимента PR #40 — `pupper_four_bl20_simple.json`. Масса модели ≈1,805 кг; настоящая 30-мешевая CAD-сцена MuJoCo; использовать архив оригинальных CAD/STL **только в личном Google Drive**, в GitHub не публиковать.

Исходные точки стоп фиксируются в мировых координатах из сохранённого `qpos`. Для каждой гипотетической позы корпуса ограниченная IK решает углы **трёх заранее заданных несущих ног** (или всех четырёх). Рассчитанная настоящей моделью CAD проекция COM затем проверяется по фактическому геометрическому треугольнику этих **намеченных** стоп. Только для прошедших кинематику и margin решается статическая LP опорных сил и моментов.

Параметры номинального математического фильтра: `|q_leg|≤1.7 рад`, `|τ_leg|≤0.7 Н·м`, `μ=1.1`, ошибка IK точки toe `≤0.8 мм`, геометрический статический запас `≥10 мм`. Все эти пределы — **исследовательские**, не характеристики железа. В этой серии *не* выполнялся `mj_step`, не измерялись реальные `Fz`, не проверялись гарантированный клиренс свободной стопы, непрерывное достижение позы и отсутствие пересечений при переходе.

## Результат A — одинаковые высота и ориентация корпуса

Сетка 13×13: `ΔrootX∈[-90,+90] мм`, `ΔrootY∈[-135,+45] мм`, шаг 15 мм. Для каждой из 169 точек:

| Режим | Прошло ограниченную IK + статическую LP + margin |
|---|---:|
| Закреплены все четыре рабочих toe | 16/169 |
| Закреплены `mr, bl, br` (планируется снять `ml`) | 3/169 |
| Закреплены `ml, bl, br` (планируется снять `mr`) | 2/169 |

**Пересечений на этой дискретной сетке нет.** Это не утверждение, что пересечение непрерывных достижимых областей пусто: сетка конечная, решатель локальный.

Рисунок с областями COM и полные записи — в [архиве Drive](https://drive.google.com/file/d/1aSJ5jsqYyqGgncntG3Xp28Eu06GREijE/view).

Для каждой ноги 375 поз: ограниченные XY, высоты +0/+15/+30 мм и World-X/World-Y наклоны `(−8°,0),(0,−8°),(0,0),(0,+8°),(+8°,0)`.

- `mr`: 9/375.
- Всего 35/750 кандидатных трёхопорных поз.
- **0/35** сохраняют исходную четвёртую стопу на земле в *том же* положении корпуса по дополнительной 4-опорной IK-проверке.

### Более строгий геометрический вывод для этих 35 поз

Для конкретного положения корпуса можно независимо от метода IK вычислить расстояние от его тазобедренного шарнира до *исходной* точки четвёртой стопы. Верхняя граница этого расстояния по неравенству треугольника — сумма постоянных длин звеньев. По фактической CAD-геометрии она составляет **256,635 мм**.

Во **всех 35** найденных целевых трёхопорных состояниях оставление четвёртой стопы в исходной точке нарушает даже эту максимально щедрую геометрическую границу:

| Кандидат 3 опор | Ближайшая исходная четвёртая стопа к hip среди 3-опорных кандидатов | Превышение 256,635 мм |
|---|---:|---:|
| `ml` свободна | 276,225 мм | **19,590 мм** |
| `mr` свободна | 301,547 мм | **44,912 мм** |

Это **строгое необходимое ограничение только для этих 35 точно заданных поз корпуса**: сохранить первоначальную четвёртую стопу неподвижной до такой позы невозможно при любой комбинации углов её трёх суставов. Но после **её отрыва** ногу можно перемещать в воздухе, поэтому из этих чисел НЕ следует невозможность перехода при иной подготовке и схеме контактов. Отсутствие физически достижимого пути к трёхопорным позам этими расчётами не доказано.

## Чего не доказали

1. Не доказана пустота глобального множества допустимых COM; это конечная численная выборка с локальной IK, без допустимых произвольных ориентаций, переменных положений стоп и непрерывности.
2. Три заданные опоры математически могут держать статическую нагрузку; **свободная нога в этих виртуальных конфигурациях не проверена на клиренс/столкновения**, а её положение не получено движением. Поэтому `screen_pass` — не физический `PASS`.
3. Из одного исходного footprint нельзя заключать невозможность 4-ногой периодической ходьбы вообще. Другие исходные позиции toe, предварительная перестановка с помощью передних ног, изменение распределения массы или углы/высота корпуса могут изменить задачу.
4. Отсутствие найденной совместной точки **не является сертификатом** отсутствия непрерывного 4→3 перехода.

## Что теперь действительно имеет смысл проверять

Вместо продолжения поочерёдной оптимизации `ml/mr/bl/br`: искать *одновременно* исходный 4-стопный footprint и **связный путь** в пространстве достижимых конфигураций с настоящим подъёмом, опусканием, контактной комплементарностью, силовыми ограничениями и периодическим замыканием. До этого полезен предварительный независимый аналитический фильтр по максимальной длине каждой кинематической цепи. Любые негативные ответы классифицировать как `NOT_FOUND_WITHIN_BOUNDS`, пока не получен действительный сертификат глобальной неразрешимости.

## Воспроизведение

Все завершённые в этой серии скрипты и JSON представлены в архиве. При использовании нужны восстановленная исходная CAD30, зависимости Python 3.13 / MuJoCo / NumPy / SciPy и настоящий экспериментальный JSON `pupper_four_bl20_simple.json` (архив PR #40).

Пример установки путей без публикации сторонних CAD-файлов:

```bash
export CAD30_RESEARCH_ROOT=/path/to/restored/periodic_work
python scan.py 0 ml mr
python scan_four.py
python height_sensitivity.py
python tilt_sensitivity.py
python tilt_four_overlap.py
python geometric_limit.py
python -m unittest test_receipts.py -v
```

**Происхождение:** SHA256 оригинальной сцены, сохранённого физического состояния и вычисленных JSON в `summary.json` и `SHA256_RECEIPTS.json`. `main` не менять, никакие исследовательские PR не сливать без разрешения.
