# CAD30 — ограниченный математический поиск периодической четырёхногой походки

**5 ноября 2026 · Статус: NOT_FOUND_WITHIN_BOUNDS, не доказательство невозможности.**

Исследовательская задача [Issue #50](https://github.com/Dmitry-dev-pet/alfred-hexapod-lab/issues/50), математический контракт draft PR #53. Никакой походки на настоящем роботе и новых физических прогонов нет.

## Что выполнено

- Полная 2D сетка выбранных параметров: 4 варианта сведения средней пары, 3 варианта её продольного сдвига, 2 варианта раздвижения задней пары и 3 варианта её продвижения = 72 четыреопорные расстановки; 24 порядка четырёх swing в каждой = **1 728** траекторий. Ось продвижения **+Y**, шаг каждой стопы за период **20 мм**. Положение корпуса на каждом из четырёх шагов **оптимизировалось совместно на целый период** по линейной программе для запаса триподной устойчивости не менее 10 мм и ограниченного смещения COM. Не использовалось выполнение отдельного шага с последующей локальной "починкой". 
- Двумерная необходимая проверка: 1 728/1 728 допустимы. Она почти не отбирает кандидатов — **нельзя выдавать 2D-проходимость за походку**.
- Из 72 разных footprint проверены истинные 3D CAD кинематика (положение суставов при предполагаемой четырёхопорной стойке) и статическая LP опорных сил: **48/72** проходят с модельными ограничениями. Подготовительный **физический путь** из шести опор к этим стойкам не проверялся.
- Для 48 статически допустимых footprint проверены по **2 лучших порядка шагов** (всего **96**): совместные 2D-цели + последовательные 3D IK и статические LP в начальном положении, при переносах корпуса, в swing и при замыкании периода. **0/96** прошли полный дискретный 3D-отсев; во всех случаях первый зафиксированный барьер — недостижимость заданной точки стопы в пределах 0,8 мм при |q|≤1,7 рад и попытке удержать вычисленный COM. Из них **84** отказа во время предварительного переноса корпуса к следующей ноге и **12** на фазе swing.
- Дополнительная частичная проверка с допуском IK 2 мм: **0/72** пройденных, проверено 72 из 96; это не полная матрица чувствительности и не доказательство невозможности.

## Ограничения и точная трактовка

- Поиск **не исчерпывающий**: не оптимизировались непрерывно все footprint одновременно с траекторией, высота/ориентация корпуса фиксированы, план смены опор задан дискретно. Локальный IK может останавливаться в локальном минимуме. Статические LP и конечные узлы не гарантируют физический переход.
- Цель положительного суммарного продвижения через три периода учитывает первоначальное смещение COM назад из физической шестиопорной подготовки, но реальный путь к предполагаемой начальной четырёхопорной стойке пока НЕ рассчитан.
- **G1 полного математического решения не пройден. G2 физической проверки не запускался**, потому что нет допустимого полного периода.
- Не изменять принятую номинальную модель и лимиты |q|≤1,7 рад, |τ|≤0,7 Н·м и μ=1,1 для объявлений об успехе; это исследовательские допущения, не характеристики реальных серв.

## Повторение

Требуется Python 3.13, NumPy/SciPy, MuJoCo 3.14 и приватная CAD30-модель из существующей папки Freenove-CAD-source на Drive. Изначальная сохранённая шестиопорная поза и поднятая пара — из PR #40. Исходники помещены рядом с этим отчётом, а исходные бинарные STL остаются только на личном Drive.

```bash
export CAD30_ROOT=/path/to/restored/CAD30-root
export CAD30_BASELINE_DIR=/path/to/restored/Pupper-physical-states
python search_global_geometry.py
python check_stances.py
python periodic_3d_screen.py
python -m unittest test_search_receipts.py -v
```

`GLOBAL_SEARCH_RECEIPT.json` содержит границы поиска, размеры выборок, причины первых отказов, SHA-256 привязки исходных файлов и явный статус. Полные кандидатные векторы и промежуточные результаты содержатся в архиве Google Drive; исходные большие файлы не включать в GitHub. Не создавать новый независимый PR для очередного локального шага; продолжать исследование именно **полной периодической задачи**.
