# Freenove FNK0052 — численная оптимизация стойки на четырёх ногах (2026-11-04)

## Результат и статус

**Частичный положительный результат, непрерывной четырёхногой ходьбы пока нет.** На CAD30 в MuJoCo подобрана новая поза корпуса, заметно улучшающая геометрические условия для подъёма средней ноги. Пробный подъём средней ноги после дополнительной перестройки центра масс **физически произошёл**, но приводам понадобилось насыщение заданного момента ±0,7 Н·м в ~19,6% тактов. Это **не принято** как безаварийный шаг. Самообучение, рефлекс и CPG в этой ветке не реализуются: цель — сначала определить физически допустимые положения.

Исследование выполнялось непосредственно в локальной среде Python 3.13.5 / MuJoCo 3.14.0, без GitHub Actions как вычислителя. Исходник — Freenove FNK0052 CAD30: 30 проверенных STL (только приватный внешний кэш), две отсутствующие детали заменены визуальными прокси. Масса **1,804868 кг** расчётная; torque cap **0,7 Н·м** условный. Неизвестны фактическая мощность RC-сервоприводов, кривая момент–скорость, ток, нагрев, PWM и реальные коэффициенты трения.

## Геометрия

В проверенной высокой стойке передняя пара уже поднята в воздух, четыре опорные стопы находятся примерно:

| Стопа CAD | X, м | Y, м |
|---|---:|---:|
| `ml` средняя левая | −0,235 | +0,000 |
| `mr` средняя правая | +0,235 | +0,000 |
| `bl` задняя левая | −0,144 | −0,198 |
| `br` задняя правая | +0,144 | −0,198 |

Исходная проекция центра масс около `(0, −0,023)` м. Пересечение диагоналей этого четырёхугольника около `(0, −0,122)` м — практически на **99 мм позади** исходного центра масс. Для статически допустимого подъёма средней ноги при неподвижных стопах требуется ещё и боковой перенос: ближайшая точка с 5-мм геометрическим запасом лежит около `(±0,043, −0,106)` м.

**Математическое ограничение:** один неподвижный центр масс нельзя разместить с положительным запасом во всех четырёх треугольниках, которые возникают при поочерёдном удалении каждой вершины выпуклого опорного четырёхугольника. Поэтому оптимальной одной позы недостаточно для *всех* фаз медленной четырёхногой походки. Но оптимизация **стартовой** позы и фазовых перемещений способна заметно облегчить задачу.

## Воспроизводимый поиск

1. Кинематика: 1400 заданных комбинаций сдвига корпуса X/Y/Z и тангажа при четырёх **неподвижных стопах**. 131 имеют максимальную ошибку обратной кинематики не выше 4 мм. Оценка квазистатическая; не считать это динамически достигнутыми позами.
2. Физика: 18 исходных + 10 уточняющих вариантов в MuJoCo. Корпус свободен, исполнительные суставы управляются PD, стопы имеют реальные solver-контакты, корневое тело не перемещается искусственно. Критерии позы: все четыре опоры, обе передние лапы в воздухе, наклон менее 8°, ни одного такта насыщения момента. Из 28 проверенных команд 24 выдержали эти критерии при `μ=1,1`.
3. Выбор с заранее указанным **дополнительным консервативным бюджетом 0,55 Н·м**: целевое перемещение корпуса от проверенной начальной высокой стойки `(ΔX=0, ΔY=−0,090, ΔZ=+0,020) м`, без заданного тангажа. В реальной динамике центр масс переместился примерно на **75 мм назад** (не на все 90 мм цели), фактический наклон **4,64°**, максимум **0,537 Н·м**. Дефицит запаса устойчивости при удалении любой средней ноги снизился с ~**−92 до −27 мм**. **Ногу ещё нельзя поднимать с этим положением корпуса без следующей фазовой коррекции.**
4. Максимальный прогресс в выбранной сетке: `(0, −0,095, +0,020) м`, фактический наклон **5,81°**, максимум **0,646 Н·м**; дефицит ~**−26 мм**. Это уже слишком близко к модельному пределу, чтобы предпочесть варианту с большим запасом привода.
5. Пробный контроль при μ=0,6 / 0,3: консервативная стойка **не проходит** прежние условия — на μ=0,6 насыщение примерно в 53,7% тактов для цели −90 мм; на μ=0,3 передние касаются пола и насыщение почти сплошное. Это не универсальная оптимальная поза для любого покрытия.
6. Отдельный квазистатический поиск по трём опорам (рассматривая одну среднюю ногу в переносе): 1440 комбинаций, 222 имеют ошибку IK ≤5 мм по **трём остающимся ногам**; 59 из этих геометрически достижимых положений дают положительный запас опоры. Но динамическая возможность ещё под вопросом.

## Первая физическая трёхопорная фаза — только предварительный результат

Тест с целевой позой `(ΔX=+0,070, ΔY=−0,120, ΔZ=+0,045) м, тангаж +8°`, при высоко поднятых передних лапах и замене положения средней левой ноги:

- Фактически средняя голень оторвалась от пола на **31,5 мм**.
- Три остальные опорные ноги оставались в контакте в контрольном интервале.
- Проекция центра масс находилась внутри их опорного треугольника с запасом **27,5 мм**; фактический наклон **4,17°**.
- **Но команды приводов насыщались 19,63% всех тактов**. Из-за этого строгий критерий принятия шага **не пройден**. В этом тесте выбранная средняя нога перед отрывом получала команду к геометрически недостижимой промежуточной опорной позе (IK-ошибка >5 см), поэтому реализация является только диагностическим поиском, а не готовым контроллером.
- Проверены отдельные варианты уменьшения PD-усиления и плавного совместного переноса: насыщение или потеря правильной опоры сохранялись. Это не основание увеличивать мощность двигателя в XML или объявлять цикл завершённым.

**Важно:** модель использует опорный полигон как *оценочный* признак, а не доказательство динамической устойчивости. Это один перенесённый сегмент, не последовательность четырёх шагов, не реальное продвижение корпуса за полный цикл и не перенос на железо.

## Воспроизведение

Для выполнения нужны Python 3.13 / MuJoCo 3.14.0 / NumPy / SciPy, а также уже восстановленные из приватного источника `source/meshes` и `source/mjcf/scene_local30_nominal.xml` с проверкой исходных хешей; ни один оригинальный Freenove STL в GitHub не включать. При запуске из корня репозитория:

```bash
python experiments/cad30/optimize_four_leg_kinematics.py
python experiments/cad30/optimize_four_leg_three_support.py
python experiments/cad30/optimize_four_leg_sweep_dynamics.py
python experiments/cad30/optimize_four_leg_sweep_focused.py
python -m unittest discover -s experiments/cad30 -p 'test_*.py' -v
```

Зафиксированная опорная поза (малый JSON `results/optimized_four_leg_guard_reference_2026-11-04.json`) взята из действительной симуляции высокого подъёма передней пары. В исследовательских продолжениях **скорость root обнулена**. Это полезная локальная проверка динамики, но ещё не доказательство полной траектории от исходного положения шестиногого робота.

### Результаты и файлы

- `experiments/cad30/optimize_four_leg_pose_dynamics.py` — свободная MuJoCo-физика заданной позы, без искусственного перемещения root.
- `experiments/cad30/optimize_four_leg_middle_liftoff.py` — отрыв средней ноги, контроль предела момента.
- `experiments/cad30/optimize_four_leg_kinematics.py`, `optimize_four_leg_three_support.py` — пространство достижимости и поддержка.
- `experiments/cad30/test_optimized_four_leg_pose.py` — воспроизводимые тесты, в т. ч. **отрицательные**.
- `results/optimized_four_leg_posture_summary_2026-11-04.json` — компактная сводка, все 28 вариантов и стресс-тесты записаны отдельно в JSON; полные 2-мс трассы и диаграммы вынесены в Drive.

## Следующий шаг (без нейросети)

Оптимизировать **не одну позу, а четыре последовательные фазы**: сдвиг корпуса → разгрузка нужной ноги → перенос стопы → постановка с нагрузкой и возврат в новый цикл. Целевая функция — пройденное расстояние при 
`τ<0,7 Н·м`, отсутствии недостижимых IK-команд, учёте скорости двигателя, опоры и трения. Нужна независимая проверка всей последовательности, а не только красивого кадра. До положительного цикла из четырёх ног задача физической возможности остаётся открытой.
