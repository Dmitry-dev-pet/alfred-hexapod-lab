# FNK0052 CAD30 — можно ли идти на 4 ногах с поднятыми передними?

Эксперимент 2026-11-04. **Предварительное подтверждение одного шага задней ноги, а НЕ непрерывной четырёхногой ходьбы.**

## Зачем

Обе передние ноги (`fl`, `fr`, номенклатура CAD) подняты высоко, как «руки». Оставшиеся четыре (`ml`, `mr`, `bl`, `br`) должны поддерживать свободно движущийся корпус. Для перестановки одной из этих четырёх ног робот фактически переходит к опоре на три оставшиеся, и центр масс должен оставаться внутри соответствующего треугольника контактов (либо требуются динамическая стабилизация и перехват падения).

## Модель, ограничения

- Источник: Freenove FNK0052 CAD30, 30/32 оригинальных STL из зафиксированного стороннего MJCF, 6 mesh-контактов голеней; два оригинальных STL заменены **только визуальными** прокси. Оригинальные CAD активы не публикуются и в этом PR не содержатся.
- MuJoCo 3.14.0, шаг 2 мс, свободный корпус, никаких фиксаций ног и внешних сил. 18 серво ног, два серво головы; PD: Kp=7, Kd=0.32, условная отсечка ±0.7 Н·м. Реальные PWM, скорость/момент, питание, трение, люфт и физические массы **не измерены**.
- Подготовка: 1 с стояния на шести ногах; **жёстко запрограммированное** смещение четырёх опорных стоп на +20 мм по Y (корпус свободно сдвигается назад); поднятие двух передних стоп (целевой подъём +105 мм и перенос вперёд +50 мм). Затем одна из оставшихся опорных ног пытается выполнить цикл подъём/перенос/опускание с целевыми +10 мм по Y и +10 мм по Z. Время одного полного прогона — 7,5 с после стабилизации.
- Только проверка достижимости и контактов, **не** рефлекторное управление, не neuroWalknet и не периодическая походка.

## Наблюдения на неизменной серии условий

Из 8 заранее заданных испытаний 5 квалифицированных одиночных шагов задних ног:

| Переставляемая нога | Масса, кг (сценарий) | Трение μ | Реальный перенос стопы | Мин. запас центра масс при переносе | Насыщение |
|---|---:|---:|---:|---:|---|
| Задняя левая `bl` | 1.644 | 1.1 | 9,31 мм | 6,86 мм | нет |
| Задняя левая `bl` | 1.805 | 1.1 | 9,32 мм | 6,47 мм | нет |
| Задняя левая `bl` | 2.080 | 1.1 | 9,28 мм | 5,42 мм | нет |
| Задняя левая `bl` | 1.805 | 0.6 | 10,30 мм | 6,05 мм | нет |
| Задняя правая `br` | 1.805 | 1.1 | 9,30 мм | 6,47 мм | нет |

Во всех этих опытах обе передние ноги не касались пола в фазе шага, и **три остальные опоры сохраняли контакт**. Для номинального сценария пиковый расчётный момент ≈0.537 Н·м, при μ=0.6 — ≈0.653 Н·м. Просвет передних ног — десятки миллиметров, у переставляемой задней голени достигал ≈9 мм.

**Отрицательные контроли:** при μ=0.3 задняя нога не оторвалась достаточно надёжно, разрывалась трёхопорная поддержка, насыщение по условному моменту ≈68% отсчётов. Для `ml` и `mr` такой же заранее заданный перенос не позволил получить чистый шаг. В сохранённом физическом снимке перед переносом, при четырёх контактах, геометрические COM-margin после удаления по одной опоре были приблизительно:

- `bl` и `br`: **+6,9 мм** — остаётся маленький положительный запас.
- `ml` и `mr`: **−103 мм** — без дополнительной перестройки трёхопорная стойка геометрически неустойчива.

Робот **не пошёл вперёд**: наблюдаемый сдвиг корпуса в основном обусловлен подготовительным смещением веса назад; один шаг стопы сам по себе не есть продвижение всего робота. Не считать результат доказательством четырёхногой походки или переносимости на реальные MG996R.

## Воспроизведение

После восстановления приватных оригинальных CAD30 assets в `experiments/cad30/source/` и установки MuJoCo 3.14.0 в Python 3.13:

```bash
python experiments/cad30/probe_four_leg_rear_step.py --foot bl --step .01 --lift .01 --shift .02 --record --out experiments/cad30/results/four_leg_rear_nominal_trace.json
python experiments/cad30/sweep_four_leg_step_probe.py
python -m unittest discover -s experiments/cad30 -p 'test_four_leg_step_probe.py' -v
xvfb-run -a env MUJOCO_GL=glfw python experiments/cad30/render_four_leg_step_probe.py experiments/cad30/results/four_leg_rear_nominal_trace.json /path/to/output
```

Численный итог эксперимента: `results/four_leg_step_probe_2026-11-04.json`. Фотография и MP4/GIF — на Drive, **получены из действительных qpos MuJoCo**, не из постановочных кадров.

## Следующая научная задача

Не заставлять все четыре ноги шагать заданным порядком. Первым делом реализовать **подготовку трёхопорной конфигурации с обратной связью**: перед подъёмом любой ноги переносить нагрузку и позицию корпуса в область опор оставшихся трёх; сравнить с этим нулевым «жёстким» протоколом. Затем получить минимум 3 полных шага каждой из четырёх ног при сохранении передних в воздухе, без падения и с положительной суммарной пройденной дистанцией. Использовать локальные соседские сигналы нагрузки/контакта и наблюдения IMU; физика MuJoCo даёт истину только для оценки, а не как бесплатный датчик на будущей плате ESP32.

Вся физическая модель расчётная. GitHub Actions не использовался как симулятор. Не сливать draft без одобрения владельца.
