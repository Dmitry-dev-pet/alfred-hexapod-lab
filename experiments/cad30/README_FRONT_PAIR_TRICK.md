# Первое упражнение на баланс: две передние ноги в воздухе (CAD30, 4 ноября 2026)

**Статус:** проведённый локально динамический численный эксперимент. Не автономная нейросеть и не эксперимент с реальным Freenove. Отдельная ветка, не сливать без одобрения.

## Проверяемая идея

Попробовать одновременно поднять обе передние ноги `fr`/`fl` (координатно передние ноги в CAD, относительно исходного Freenove left/right есть зеркальность). Сначала сравнить два программно заданных варианта: без подготовки баланса и с предварительным переносом корпуса назад за счёт команд четырём опорным ногам. Не перемещать корень робота искусственно, не прикреплять стопы к поверхности.

## Среда и фиксированный протокол

- Freenove FNK0052 CAD30, upstream `MattiaGrigoli/autonomous_hexapod@5c9a84c`; 30 проверенных исходных STL, недостающие 2 элемента только визуальные; реальный в рамках MuJoCo контакт исходных 6 голеней с полом.
- MuJoCo 3.14.0 на Python 3.13, шаг физики 2 мс, контроль каждые 20 мс.
- Предварительно найденная стойка на шести ногах в течение 1 секунды.
- Режим `shift=0`: передние ноги поднимаются без изменения исходных целевых углов остальных четырёх ног.
- Режим `shift=0.04`: в течение 2 с четыре опорные ноги изменяют цель стопы в системе исходного корпуса на +40 мм по передней оси CAD (`+Y`); **корпус физически перемещается назад**, без команды на перемещение корня. 2–3 с: плавный подъём передних ног на 35 мм командного перемещения, 3–4 с: удержание, 4–5 с: опускание, 5–6 с: возвращение исходной стойки.
- PD `Kp=7`, `Kd=0.32`, лимит ±0.7 Н·м по приводам; **условные** параметры без проверки реальных серв.
- Номинальная масса 1.804868 кг; отдельная контрольная сетка 1.644 / 1.805 / 2.080 кг × μ=1.1/0.6/0.3. μ не измерен.
- Трюк засчитывается только при всех четырёх касаниях задних/средних ног, отсутствии касаний обеих передних, просвете нижней CAD-геометрии обеих передних ног >4 мм, положительном запасе по проекции центра масс в выпуклом многоугольнике **фактических контактных точек** четырёх опор, наклоне <10° в окне 3.25–3.95 с и отсутствии падения.

## Результат на номинальной массе, μ=1.1

| Режим | Подъём обеих передних ног | Мин. просвет в окне удержания | Мин. запас COM | Макс. наклон | Пик момента |
| --- | --- | ---: | ---: | ---: | ---: |
| Без предварительного смещения | Не выполнен | 0 мм | −22.82 мм | 7.885° | 0.446 Н·м |
| Целевая перестановка опор на +40 мм | **Выполнен** | **19.40 мм** | **+22.74 мм** | **2.548°** | **0.456 Н·м** |

Запланированный сдвиг целей стоп на 40 мм дал физическое смещение корпуса по Y ≈ −34 мм (в окне удержания). При нулевом сдвиге COM не оказался в опорном многоугольнике, поэтому передние ноги не разгрузились полностью.

## Воспроизведение

1. Восстановить `source/mjcf/base.xml` и 30 исходных STL в `source/meshes/` из ранее сохранённого **приватного** архива на Google Drive (`Alfred-Hexapod-Lab/Freenove-CAD-source`); не добавлять закрытые лицензионные STL в GitHub.
2. Запустить `python experiments/cad30/build_30meshes.py` и проверить SHA оригиналов.
3. Выполнить:

```bash
python experiments/cad30/front_pair_trick.py --shift 0 --lift 0.035 --scenario nominal --mu 1.1 --out results/front_pair_baseline.json
python experiments/cad30/front_pair_trick.py --shift 0.04 --lift 0.035 --scenario nominal --mu 1.1 --frames --out results/front_pair_balance.json
python -m unittest discover -s experiments/cad30 -p 'test_front_pair_trick.py' -v
xvfb-run -a env MUJOCO_GL=glfw python experiments/cad30/render_front_pair_video.py results/front_pair_balance.json results/front_pair_media
```

Код `render_front_pair_video.py` только воспроизводит записанные динамические `qpos`. Он не анимирует выдуманную траекторию. Удалить/не публиковать исходные CAD-меши за пределами приватного архива.

## Что НЕ доказано

Это **централизованно заданная подготовка стойки**, не локально возникшая коррекция и не нейронное управление. Не проверены возмущения, шум/задержка датчиков, расхождения CAD-касания с реальной резиновой стопой, фактическое трение и характеристики сервоприводов; всего 6 секунд, нет повторов с случайными состояниями. Контрольная сетка варьирует сценарную массу и трение, **не является рандомизированной независимой выборкой**.
