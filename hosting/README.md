# Приватная веб-публикация плеера

`scripts/build_hosted_player.py` переносит существующий `docs/` в статический
`dist/` отдельного Sites-проекта. Структура каталога и записанные физические
состояния сохраняются. Локальные Python API не входят в веб-приложение.

**Новый механизм:** после однократного обновления существующего ChatGPT Site
(см. [LIVE_GITHUB_CATALOG.md](LIVE_GITHUB_CATALOG.md)) каталог и неизменяемые
3D-записи подгружаются напрямую из рабочей ветки GitHub с проверкой SHA-256.
Кнопка «Проверить обновления» теперь сверяет GitHub, а не статический
`hosted-version.json`. После появления нового эксперимента в GitHub
повторная сборка Site больше не нужна.

Однократное обновление старой публикации всё ещё необходимо, чтобы
установить `github-live-sw.js` и `github-live-boot.js`. Сайт сохраняет
прежний адрес, приватность, каталог, 3D-контролы и медиатеку.

## Сборка

1. Использовать закреплённый checkout этого проекта.
2. Подготовить Three.js 0.169.0 через `tools/prepare_android_offline.py:install_three`.
   Этот существующий загрузчик проверяет SHA-512 по метаданным npm. Сохранить
   возвращённый словарь SHA-256 как `<vendor>/VENDOR_SHA256.json`.
3. При необходимости подготовить `<media>/media.json` с массивом `videos`.
   Запись: `filename`, `title`, `description`, `source_url`, `sha256`.
   MP4 должен находиться в той же директории; хеш проверяется при сборке.
   Оригиналы и архивы экспериментов сохраняются в Drive. Не коммитить их здесь.
4. Выполнить:

```bash
python scripts/build_hosted_player.py \
  --site /absolute/path/to/site \
  --vendor /absolute/path/to/verified-vendor \
  --media /absolute/path/to/verified-media
```

`--media` необязателен. В `Site/.openai/hosting.json` указать приватный
проект Sites и `static.directory=dist`. Код экспортера и шаблоны находятся
в GitHub; итоговая статическая сборка хранится в репозитории этого Site.

Исходные Freenove STL не копируются: сохранены закреплённые upstream URL и
атрибуция. Для 3D требуется WebGL и доступ к upstream-серверам моделей.
При отсутствии WebGL остаются каталог и раздел готовых видео.
Это онлайн-публикация; перенос офлайн-кеша Android не реализован.

## Проверки

```bash
python -m unittest discover -s tests -p 'test_hosted_player.py' -v
```

Проверяется целостность всех файлов каталога, отказ при испорченной записи
и отсутствие зависимости облачного обновления от локального сервера.
Проверка браузером: каталог, кнопка обновлений, выбор записи, видео,
пауза/перемотка и оригинальная 3D-геометрия при доступном WebGL.
