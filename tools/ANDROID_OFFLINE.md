# Hexapod Lab — автономный 3D-просмотр на Samsung Tab S7

Это **локальное воспроизведение записей MuJoCo**, а не запуск физического движка на Android. Источником служит отдельная ветка с трёхмерным веб-просмотрщиком и записями экспериментов (PR #20).

## Установка (однократно, нужен интернет)

Требуются Git и Python 3.10+ в Termux; Node.js необязателен и служит только для дополнительной проверки синтаксиса. Из уже созданного **точного** checkout этой ветки:

```sh
python tools/prepare_android_offline.py --source . --dest "$HOME/hexapod-viewer-local"
python "$HOME/hexapod-viewer-local/local_viewer_server.py" start
```

После сборки можно отключить интернет. Открыть на **этом же планшете** в браузере:

- `http://127.0.0.1:8808/hexapod/` — tripod, 60 секунд
- `http://127.0.0.1:8808/hexapod/claws/` — эксперимент с «клешнями»
- `http://127.0.0.1:8808/hexapod/six-to-four/` — подготовка 6 → 4 опор

Остановить сервер:

```sh
python "$HOME/hexapod-viewer-local/local_viewer_server.py" stop
```

Автозапуска и дополнительной службы Termux **нет**. Если устройство перезагрузилось или Android завершил сервер, его надо запустить снова. Сервер слушает только `127.0.0.1:8808`; доступ извне планшета не предусмотрен.

## Что выполняет установщик

1. Копирует `docs/` из локального Git checkout в **новую**, не существовавшую прежде папку. Если папка уже есть, завершается без перезаписи.
2. Проверяет наличие трёх записей MuJoCo и 30 оригинальных STL-идентификаторов в каждой.
3. Получает 30 сторонних STL **только из закреплённого публичного исходника** MattiaGrigoli/Freenove, commit `5c9a84c16335b30036e451c691d2c544abf4bc72`; каждое сверяет по SHA-256 в `tools/stl_sha256.json`. Исходные STL не коммитятся и не публикуются.
4. Загружает ровно `three@0.169.0` с npm registry, сверяет tarball по опубликованной sha512-integrity и сохраняет локально требуемые `three.module.js`, `OrbitControls.js`, `STLLoader.js` вместе с MIT LICENSE.
5. Меняет HTML import maps на локальные пути и URL STL внутри трёх локальных копий JSON. Копии исходного Git не переписывает.
6. Создаёт `OFFLINE_MANIFEST.json` и отдельный запускатель HTTP-сервера.

**Проверка:** в среде подготовки отдельно проверены SHA-256 реальных 30 STL, преобразование трёх маршрутов и манифестов, HTTP-ответы и start/stop сервера. При этом для двух дополнительных маршрутов использованы тестовые фикстуры из 60-секундной записи, а для JS-модулей — тестовые заглушки. Реальный npm download, WebGL-рендер и касания на Samsung Tab S7 **не подтверждены**: их необходимо проверить при установке; не выдавать READY_OFFLINE без этого.

**Лицензии:** исходный Freenove CAD принадлежит Freenove; публичная копия доступна через Mattia Grigoli с отдельным разрешением (см. [third-party notice](https://github.com/MattiaGrigoli/autonomous_hexapod/blob/main/LICENSE-3RD-PARTY.md)). `three` — MIT. Настоящие 30 STL загружаются на личное устройство для просмотра, но не размещаются в GitHub или публичном Pages. Отсутствующие две детали CAD остаются визуальными заглушками.

## Ограничения

Записи показывают результат уже выполненной симуляции; это не управление физическим роботом. Модельные массы, трение, сервоприводы и силовые ограничения не прошли калибровку на реальном Freenove. На Android возможны ограничения памяти/GPU. Без интернета в локальном просмотрщике можно воспроизводить уже установленные записи, но внешние ссылки на Github/лицензии при нажатии потребуют сети.


## Новый интерфейс и обновление библиотеки

После установки интерфейс оптимизирован под вертикальный экран Tab S7: при открытии сразу идёт 3D-запись; нажми её название вверху, чтобы выбрать другую симуляцию. Пауза, перемотка и скорость появляются после касания. Запись повторяется по кругу.

**Новые демонстрации:** в окне выбора нажми «Обновить библиотеку». Это отправляет одно действие существующему локальному Python-серверу на `127.0.0.1:8808`, без фонового процесса. Список поступает из ветки `feature/android-local-offline-viewer-20261104` репозитория `Dmitry-dev-pet/alfred-hexapod-lab`; новые файлы загружаются только после проверки SHA-256. Подробнее: `docs/hexapod/LIBRARY_PROTOCOL.md`.

Если локальный каталог `~/hexapod-viewer-local` был собран **раньше этой версии**, он не обновится автоматически: установщик защищает существующий каталог от перезаписи. Его необходимо переустановить в **новую** папку после сохранения старых файлов и проверки. Сервер вручную стартует пользователь; Codex не нужен.


## Обновить старую установку без повторного скачивания STL

Если viewer уже был установлен до нового portrait UI, **сначала останови сервер вручную**:

\`\`\`sh
python "$HOME/hexapod-viewer-local/local_viewer_server.py" stop
\`\`\`

Обнови исходную ветку (из существующего checkout PR #24):

\`\`\`sh
cd "$HOME/hexapod-viewer-android-20261104-src"
git pull --ff-only
python tools/upgrade_android_ui.py --source . --dest "$HOME/hexapod-viewer-local"
python "$HOME/hexapod-viewer-local/local_viewer_server.py" start
\`\`\`

Скрипт обновляет **только** HTML/JS интерфейса и локальный сервер, сохраняет старые файлы в \`backup-ui-...\`, не трогает 30 STL, Three.js и физические записи. Отклоняет запуск, если порт 8808 занят, если контрольные суммы STL неверны или если исходники не совпадают с ожидаемой структурой. Каталог уже сохранённых дополнительных экспериментов не заменяется.

Новая установка по \`prepare_android_offline.py\` и так включает portrait UI и этот же сервер. Любые обновления через браузер относятся к записям библиотеки, **не к обновлению кода самого интерфейса**.
