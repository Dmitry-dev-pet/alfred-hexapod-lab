# Hexapod Lab V11 — разворот корпуса с опорой на землю

**Дата:** 2026-11-06. **Модель:** Freenove FNK0052 / приватная CAD30. **Исправление пользовательской ошибки:** «Поворот корпуса не верно, крутится весь гексапод, а не стоит на земле».

## Почему V10 выглядел неправильно

В V10 (как и V9) рендер опирался на свободно интегрируемую позицию/ориентацию корневого звена (`FactoryPilot.{x,y,yaw}`), особенно при повороте во время ходьбы. Синхронизированного требования закрепить опорные стопы в мировой системе координат не было. Тело можно было повернуть «через» неподвижную сетку пола, пока опорные стопы скользят. При смешивании ходьбы и `CMD_ATTITUDE` суставные цели получались суммированием таблиц.

Таблицы V7 для изолированного **крайнего** разворота корпуса уже содержали правильную компенсацию ногами (±15°). Но V10 интерполировал суставы между нейтралью и крайними позами без точной обратной кинематики на промежуточных углах.

## Что изменено в V11

1. **`Разворот корпуса` в стойке:** офлайн МуJoCo `mj_forward` + SciPy IK вычислены 31 цель шести ног при −15°…+15° с шагом 1°. Все исходные мировые точки стоп зафиксированы. Браузер только интерполирует эти позы, при этом корпус действительно поворачивается относительно стоп. Никаких онлайн IK / MuJoCo / Drake.
2. **Ходьба / поворот на месте:** вместо свободного применения к рендеру `FactoryPilot` dead-reckoning корня добавлена лёгкая геометрическая оценка корня по **заранее полученным положениям CAD-стоп и текущим предполагаемым опорам**. Находятся поворот + XY-смещение наилучшего плоского жёсткого преобразования (2D Procrustes). Стопа выше 3 мм отпускает мировой якорь, при постановке якорь ставится заново. Для расчёта стоп используется существующий CAD30 FK (3D quaternion, 27 тел). Это **не модель контактов**.
3. **Два джойстика** остаются: левый всегда движение+поворот (или боковой ход), правый корпус/голова, возможно одновременное использование. Штатные Tripod/Wave, высота шага и амплитуды производителя, режим головы V5 не изменены. Старая V10 остаётся в библиотеке с пометкой; новая V11 отдельной версией из-за защиты неизменяемых файлов локального сервера.
4. Индикатор `Опоры N/6 · смещение опор M мм` — **геометрическая оценка**, не показание датчиков. Если M >4 мм или меньше 3 предполагаемых опор, появляется явное предупреждение «ОПОРЫ НЕ СОГЛАСОВАНЫ».

## Репродуцируемые численные тесты

| Сценарий | V10 макс. сдвиг опор, мм | V11, мм |
|---|---:|---:|
| Разворот во время Tripod | 56,7 | **6,93** |
| Прямая ходьба Tripod | 32,6 | **3,14** |
| Ходьба + поворот Tripod | 44,0 | **4,72** |
| Разворот во время Wave | 38,1 | **20,95** |

Значения — расчет **планарного** несоответствия заданным опорным точкам при идентичных кинематических таблицах (по MuJoCo **`mj_forward`**, без `mj_step`), НЕ физические измерения. Для Wave V11 пока **не устраняет полностью проскальзывание**; нужна отдельная офлайн-доработка траектории. Поворот на 180° не следует интерпретировать как подтверждение устойчивости или силы моторов.

В стоячем положении 31×6=186 проверок положений стоп на −15…+15°: **максимум 0,01261 мм**; при промежуточных полу-градусных положениях — **0,0151 мм**. Это проверено исходной CAD30 MuJoCo FK, а не по нарисованному экрану.

Проверка производилась с pinned `scene_local30_nominal.xml`, SHA-256 `fe9d7c292b199f19b11da220e74f826e05fb5433a43c5b46c1bc620eb34f6df3`, и исходными фабричными таблицами V7. Исходные STL и XML остаются в частной локальной среде владельца, не распространяются в этом архиве.

### Команды

С оригинальным CAD30 из приватного архива и зависимостями Python:

```bash
PYTHONPATH=. python scripts/build_planted_yaw_v11.py --scene source/mjcf/scene_local30_nominal.xml
PYTHONPATH=. python -m unittest discover -s tests -p 'test_planted_yaw_v11.py' -v
node tests/test_ground_lock_v11.mjs
node tests/test_anchor_trace_v11.mjs
python -m unittest discover -s tests -p 'test_static_v11.py' -v
```

## Не доказано и не должно вводить в заблуждение

Счётчик «Опоры» отражает *предполагаемые* опоры по высоте стопы, но не наличие ненулевой силы Fz. Есть систематические ошибки при переходах: 2 опоры на отдельных фазах Tripod, смещение до 21 мм при Wave; при этом браузер предупреждает. Отдельно не проверены динамическая устойчивость, контактные силы, момент 18 сервоприводов, реальные PWM нули/лимиты, столкновения, slip и mixed body+walk. **Запрещено использовать этот предпросмотр для управления реальными моторами без физического теста и калибровки.**

Проверки на самом сенсорном экране Samsung Tab S7 пока нет. Физика в реальном времени в браузере не выполняется.
