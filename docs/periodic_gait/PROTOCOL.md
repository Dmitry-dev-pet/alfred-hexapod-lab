# CAD30 / P0 — существование периодической четырёхногой походки

**Основная задача — Issue #50.** Связано с #21, #26, #38, draft PR #43–#52. Дата: 5 ноября 2026. Статус: **строгий протокол и критерии; полного решения пока нет**. Не считать отдельные успешные переносы ног доказательством походки.

## Научный вопрос

Существует ли у исходной CAD30-модели Freenove FNK0052 с поднятыми `fl/fr` **периодическое** квазистатическое/динамическое движение на `ml/mr/bl/br`, в котором все четыре стопы действительно отрываются и приземляются, после чего то же движение можно повторять с положительным смещением всего корпуса вперёд?

Мы ищем **весь период одновременно**, а не следующий шаг и не фиксированные 218 отдельных поз.

## Математическое условие периодичности

Обозначим `z(t)=(r(t),R(t),q(t),v(t))`: мировая позиция и ориентация корпуса, 18 углов ног, все скорости. `p_i(t)` — мировая позиция стопы. Ось движения — `+Y`.

Для некоторого `T>0` и `Δ>=0.020 m`:

- `r(T)=r(0)+(0,Δ,0)`;
- `R(T)=R(0)`, `q(T)=q(0)`, `v(T)=v(0)` (с явными допусками);
- `p_i(T)=p_i(0)+(0,Δ,0)` для **каждой** из четырёх ног;
- режим контакта на обеих границах периода одинаков: четыре несущие ноги, обе передние подняты;
- в течение периода **каждая** `ml,mr,bl,br` один раз проходит полную последовательность liftoff → clearance → landing;
- начало следующего периода соответствует конечной позе с трансляцией `Δ` и не требует новой скрытой подготовки.

Условные допуски первого скрининга: `max|q_end-q_start|<=0.03rad`, `max|qd_end-qd_start|<=0.1rad/s`, ошибка поворота корпуса `<=0.035rad`, высоты `<=5mm`, расхождения смещений toe/body `<=5mm`. Это допуски **поиска**, а не утверждённая точность реального робота.

## Чистое продвижение: не скрывать подготовку

Обозначим `Y6` — исходный COM-Y в шестиногой стойке, `Y0` — COM-Y после **всей** подготовки, `Δ` — ход за установившийся период.

Условия: `Δ>=20mm` **и** после трёх полных периодов `Y0+3Δ-Y6>=20mm`. Отдельно публиковать `prep_delta`, `cycle_delta`, `net_from_original_six`. Если ради шага `bl` нога `ml` ушла на −85мм или корпус отведён назад, это часть баланса и не должно исчезать из метрики.

## Уравнения и ограничения

```text
M(q) qdd + h(q,qdot) = S tau + J_contact(q)^T f_contact
tau = clip(Kp*(q_target-q) - Kd*qdot, motor_limits)   [для позиционного PD]
gap_i >= 0, lambda_i >= 0, gap_i * lambda_i = 0      [идеальный контакт]
friction and no-slip constraints on stance feet
```

Свободные переменные: начальная четырёхопорная стойка; позиции всех четырёх стоп; порядок шагов (до 24 вариантов); траектории корпуса, суставов, контактов и сил; длительности фаз; исходная шестиногая подготовка. Нельзя назначать `Fz` силой воли: контакт проверяется в модели. Исходная физическая модель: 30 оригинальных CAD-деталей **только в приватном Drive**, исследовательские параметры `μ=1.1`, масса ≈1.805 кг, `|q_leg|<=1.7rad`, `|tau_leg|<=0.7Nm`. Это **не паспортные пределы**.

Квазистатическая проверка — лишь **необходимый фильтр**: COM внутри треугольника **фактически несущих трёх опор** с начальным запасом ≥5мм, желательно ≥10мм; статическая LP по `Fz`, трению и моментам; кинематика и CAD-коллизии, проскальзывание, клиренс. Успешные статические узлы **не доказывают** физически реализуемых переходов и не дают права на `PASS`.

## Единый эксперимент — только в этом порядке

**G0 / provenance.** Зафиксировать точный физический исходный шестиногий `qpos/qvel/PD goal`, координатную систему, оригинальную CAD30-модель, массы/трение/приводы, версии и SHA256. Перенос на настоящий Freenove НЕ выполнять.

**G1 / существование периода.** Искать **одновременно** весь контактный четырёхшаговый цикл плюс достижимую подготовку из шести опор, используя MuJoCo+Mink+SciPy/QP или Drake при необходимости. Оптимизировать положительное `Δ`, запас по контактам/моментам, стоимость подготовки и достижимое повторение; проверить непрерывные переходы, а не только sampled snapshots. Найденный вариант классифицировать `GLOBAL_SAMPLED_CANDIDATE_ONLY`, пока не проверены непрерывная реализуемость и физика. Если не найден — `NOT_FOUND_WITHIN_BOUNDS` с точными границами поиска, **не** «механически невозможно».

**G2 / независимая динамика.** Только кандидат с замкнутым периодом прогнать **одним свободным MuJoCo MjData** от исходной 6-stance через подготовку и ≥3 полных периода; без `mj_resetData`, редактирования root `qpos` или фиктивных кадров. Каждые 2мс измерить именованные `Fz` `ml/mr/bl/br/fl/fr`, фактическую COM-геометрию, контакты, foot clearance ≥2mm, проскальзывание, `q/qd`, сырые и ограниченные моторные моменты. Во время swing — ≥3 **нужные** опоры по `Fz>=0.2N` каждую итерацию; swing leg действительно разгружается (`Fz<0.08N`), затем touchdown и полная нагруженная четвёрка. Обе передние остаются подняты. Без превышения модельных ограничений и с положительным чистым ходом от шестиногого старта.

**G3 / robustness.** После номинального успеха: `μ=0.8`, `μ=0.6`, `dt=0.001s`, изменённые массы и семена. Все FAIL записывать. Гарантии относятся **только к модели**, пока не калибровано железо.

## Стоп-правила против хождения по кругу

- **Запрещено** считать отдельный успешно поднятый `ml/mr/bl/br` очередным основным достижением без замкнутого периода и чистого прогресса.
- **Запрещено** создавать новый PR ради локального «исправления следующей ноги» до G1.
- Не создавать дублирующий Issue: главная постановка остаётся **#50**. #26/#38/PR #43–#52 — архив исходных данных и негативных экспериментов.
- Дискретные IK/LP дают только `MATH_SCREENED`, физическая одна эпоха — `ONE_CYCLE_ONLY`, только три повторяемых периода с полной 2мс-телеметрией и положительным net — `REPEATED_PERIODIC_WALK_PASS`.
- При неудаче в конечной области поиска — сохранить матрицу допустимых областей и активные ограничения; выбирать дальше между изменением footprint, распределением масс или иной походкой **по результату**, не методом бесконечной подстройки.

## Инструмент проверки глобальных критериев

Самостоятельный Python контракт/тесты не являются оптимизатором и не доказывают динамическую походку. Они должны отвергать: шаги `ml,mr,ml,bl` без `br`; продвижение стоп без корпуса; незамкнутую позу/скорость; скрытое отрицательное продвижение во время подготовки; потерю 4-контактного состояния на границе периода; превышение исследовательских лимитов. Образцы данных для unit-тестов — **синтетические**, не физические доказательства.
