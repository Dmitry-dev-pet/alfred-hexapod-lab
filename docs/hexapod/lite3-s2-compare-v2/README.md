# XGO Lite3 S2 — синхронное сравнение на планшете

Дата: 2026-11-06. Плеер **только воспроизводит** те же шесть физически рассчитанных S2-записей (seed 20261106; 96 записанных кадров на сценарий), из опубликованной библиотеки rev23. Он не рассчитывает новые шаги, не создаёт MP4, не обращается к сервомоторам и не меняет ранее опубликованные файлы.

## Почему это нужно

Старая запись S2 переключала сценарии по одному и автоматически следовала за корпусом, поэтому различия в смещении (3–13 см) трудно увидеть. Скольжение является контактной метрикой, а не обязательно видимым различием поз.

## Новый вариант

- Режим **Наложение**: бирюзовая полупрозрачная оригинальная STL-модель (исходная физика 345г), другая модель — выбранный физический S2-сценарий. Шкала времени общая.
- Режим **Два робота рядом**: две сцены пространственно разнесены на **±0,28м только для чтения**, физические траектории, скорости и суставы сохранены без изменений. Чёткая надпись предупреждает о визуальном разнесении.
- Камера по умолчанию неподвижна. Режим сверху и обычное вращение/масштабирование сохранены.
- Истинное расстояние **между положениями корпусов** в каждый момент в миллиметрах, одинаковый масштаб XY-траекторий, синхронная перемотка. Сравнение содержит **все 5 изменений относительно baseline**.
- В текстовых блоках отдельно показаны агрегаты **10 независимых прогонов на сценарий**, а не несуществующий покадровый slip-speed. Показатели из `S2_60RUN_AGGREGATE.json` (представлены с округлением до 0,1%).
- Исходные 17 STL грузятся из уже существующего локального кэша или pinned upstream и **не хранятся** в публичном GitHub; перед разбором проверяются SHA-256/size по манифесту предыдущего viewer.

## Контроль

- 6/6 локальных контрактных тестов сравнения PASS, `node --check app.js` PASS.
- Физические 96 временных отметок совпадают для всех сценариев; совпадают источник `policy.onnx`, `seed=20261106`, оригинальный vendor commit и структура 162 значений/кадр.
- Данные оригинальной траектории взяты из существующего rev23, на новом маршруте не меняются.
- Синхронное сравнение S2 завершает момент 9.5с. Для `combined_stress` расстояние между положениями корпуса в конце на одном seed = **около 114 мм**.
