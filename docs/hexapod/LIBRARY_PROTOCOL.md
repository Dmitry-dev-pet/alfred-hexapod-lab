# Hexapod Lab — динамический каталог симуляций

Библиотека на планшете показывает **отдельную запись для каждого физического эксперимента MuJoCo**. Интерфейс запускает воспроизведение автоматически, зацикливает запись и использует оригинальные CAD-сетки Freenove (локальный кэш на планшете).

## Где хранится список

- \`docs/hexapod/library.json\` в **ветке \`feature/android-local-offline-viewer-20261104\`** — каталог, который проверяет кнопка «Обновить библиотеку».
- Реальные файлы HTML/JS/CSS/JSON, относящиеся к новой симуляции, размещаются в \`docs/hexapod/\`. Отправлять в GitHub STL не надо: при установке 30 оригинальных CAD-сеток уже кэшируются локально и сверяются по SHA-256.
- Сервер принимает только явно перечисленные в каталоге новые файлы, проверяет их размер и SHA-256, сохраняет локально и **лишь затем** обновляет список. В отсутствие сети прежние записи остаются работоспособными.

## Формат новой записи

Увеличить \`revision\` и добавить запись в \`entries\`:

\`\`\`json
{
  "id": "tripod-slippery-001",
  "title": "Tripod · скользкий пол",
  "detail": "Серия экспериментов с уменьшенным трением · 12 с",
  "duration_s": 12,
  "href": "/hexapod/tripod-slippery-001/",
  "files": [
    {"path":"hexapod/tripod-slippery-001/index.html","sha256":"<64-hex>","size":1234},
    {"path":"hexapod/tripod-slippery-001/app.js","sha256":"<64-hex>","size":5678},
    {"path":"hexapod/data/tripod-slippery-001.json","sha256":"<64-hex>","size":9012}
  ]
}
\`\`\`

Публикуются **все зависимости** новой симуляции; \`sha256\` и \`size\` относятся к полным оригинальным байтам каждого файла в GitHub. Сначала коммитить файлы, затем их манифест в том же коммите (или последующим коммитом). Физическая запись должна происходить из MuJoCo, не из постановочной JavaScript-анимации.

Каждый путь неизменяем: при необходимости исправить запись, используй новую версию и новый путь. Изменение уже сохранённого файла с другим SHA-256 блокируется, поэтому старые результаты не подменяются незаметно. Не добавлять файлы из сторонних доменов, бинарные STL или материалы с неясной лицензией.

Кнопка вызывает \`POST /api/refresh\` только на локальном Python-сервере. Сервер получает текущий commit SHA разрешённой ветки GitHub и скачивает версии файлов, закреплённые этим SHA. Скрытых фоновых опросов нет. Новый статус и список возвращаются прямо в браузер.

**Ограничения:** интерфейс показывает replay, не рассчитывает физику в браузере; масштабируемая синхронизация новых симуляций требует, чтобы Альфред публиковал каждую запись в совместимом формате. Если каталог содержит ошибку или ресурсы недоступны, обновление отменяется, а ранее установленная библиотека остаётся доступной.
