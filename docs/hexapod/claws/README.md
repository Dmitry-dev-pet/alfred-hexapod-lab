# Событийный опыт «Клешни» — Three.js

Запись MuJoCo из исследовательского PR #22: `https://github.com/Dmitry-dev-pet/alfred-hexapod-lab/pull/22`.

**Не полноценная четырёхногая походка:** 10-секундная симуляция, сохранены 100 физических поз на 10 Гц и контакты из трассы 50 Гц. Две задние голени действительно поочерёдно отрывались (2,59 и 2,91 мм), средние оставались на опоре; чистое продвижение за окно с поднятыми клешнями 0,41 мм. Это не успех по критерию Issue #21.

[Интерактивная страница](./index.html): вращение и масштабирование на телефоне, пауза, перемотка, скорость, смена ракурса, данные контактов и фаз. Использует web Three.js, **не** физику в браузере. Исходные 30 STL Freenove загружаются прямо из закреплённого upstream GitHub (правообладатель — Freenove), не включены в этот сайт/репозиторий.

## Воспроизводимость

При наличии оригинального локального CAD30, полного физического отчёта из приватного Google Drive и MuJoCo:

```bash
PYTHONPATH=. python scripts/export_event_claw_replay.py
PYTHONPATH=. python -m unittest tests/test_event_claw_replay.py -v
node --check docs/hexapod/claws/app.js
```

Страница опубликована из исследовательской ветки, а не из `main`. При недоступном upstream CAD интерфейс переключается на схематическую модель. Моторные пределы, массы и трение модельные; движения реального робота не проверены.
