# MuJoCo: падение при отключении приводов

Реальная физическая траектория, не постановочная анимация. Запись начинается с 9,3-секундной подготовки Freenove CAD30 к четырёхопорной стойке B (исходный опыт — PR #25). В момент t=9,3 с обнуляются управляющие моменты **всех 18 суставных приводов**, после чего MuJoCo 3.14.0 физически интегрирует движение ещё 2,5 с при гравитации и столкновениях. Корпус оседает на ~8,5 см, наклоняется до ~21°, а `torso_simple_collision` касается пола с t≈9,5 c. Это не полный переворот на бок и не результат предыдущего исследования среднего шага.

Кадры 20 Гц получены из сохранённых qpos. 236 кадров × 27 тел; `mj_forward` восстанавливает реальные мировые позы 27 тел с оригинальными 30 STL, которые локально проверяются и кэшируются на планшете. Никакого root teleport / подмены падения в JS нет.

Физические данные, код расчёта и экспорта, SHA-256 без сторонних STL: https://drive.google.com/file/d/1saapisV4OU58EdQYknuQcq9E_y4T5amC/view .

Ограничения: масса, реальный момент сервоприводов и трение — допущения моделирования. Не проверено на настоящем Freenove. Не выдавать за удачную/неудачную четырёхногую походку. CAD © Freenove, см. https://github.com/MattiaGrigoli/autonomous_hexapod/blob/main/LICENSE-3RD-PARTY.md .
