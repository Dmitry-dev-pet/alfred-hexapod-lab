# Freenove FNK0052: сверка кинематической геометрии (2026-11-03)

Исходный commit Freenove: [`b7d228cc870b0a802d3768bfcf742f85fa8695f6`](https://github.com/Freenove/Freenove_Big_Hexapod_Robot_Kit_for_Raspberry_Pi/commit/b7d228cc870b0a802d3768bfcf742f85fa8695f6).

Это **кинематически согласованная приближённая** модель, **не** точная CAD-копия и **не** откалиброванный физический двойник.

## Первоисточник

[Freenove, `Code/Server/control.py`](https://github.com/Freenove/Freenove_Big_Hexapod_Robot_Kit_for_Raspberry_Pi/blob/master/Code/Server/control.py):

- `coordinate_to_angle(x, y, z, l1=33, l2=90, l3=110)` — эффективная длина сегментов, мм.
- `transform_coordinates(points)` — направления ног 54°, 0°, −54°, −126°, 180°, 126°, локальные радиальные вычеты 94/85 мм и смещение по высоте −14 мм.
- `calculate_posture_balance()` — `body_structure`: (55,76), (85,0), (55,−76), (−55,−76), (−85,0), (−55,76) мм.
- `body_points` — нейтральные целевые положения стоп в плоскости XY: (137.1,189.4), (225,0), (137.1,−189.4), (−137.1,−189.4), (−225,0), (−137.1,189.4) мм. Точность десятых долей мм — это округление в исходном коде, **не** паспортная точность робота.

Размеры креплений согласуются с радиальными вычетами: 94·(cos 54°,sin 54°) ≈ (55,76) мм; для передней/задней ног 85 мм.

## Выбор системы координат в MuJoCo

+X: первая группа (ноги 1–3), +Y: нога 1/6, +Z: вверх. Имена `leg1`…`leg6` сохраняют **оригинальный порядок Freenove**, не вносят путаницу «левая/средняя».

Локальный FK для одной ноги с `l=(0.033,0.090,0.110)`:

```
radial = l1 + l2*cos(hip) + l3*cos(hip+knee)
vertical = -l2*sin(hip) - l3*sin(hip+knee)
```

При радиусе `140 мм` и вертикальном смещении `−39 мм` получаем нейтральные углы:

- yaw = 0°;
- hip = −44.02°;
- knee = +111.42°.

Визуальная геометрия стопы не заменяет физический датчик касания: начальный центр стопы задан на z = 13 мм при **условном радиусе** сферы 13 мм. Начальная высота системы координат корпуса — 66 мм, из них 14 мм составляет OEM-смещение осей и 39 мм — положение стопы.

## Предположения, которые остаются непроверенными

| Характеристика | Текущий статус |
|---|---|
| Внешний профиль корпуса, размеры сервокорпусов, кронштейнов и крепежа | Условные box/capsule; требуется CAD или измерение |
| Массы корпуса (0.52 кг), отдельных звеньев, COM и инерции | Условные; без взвешивания невалидны |
| Серво: мощность, параметры PID, постоянный рабочий момент | Условные ограничения 0.70 Н·м, не паспорт |
| Геометрические пределы суставов | Расширены для достижения нейтральной позы; **не проверены по механике/серво** |
| Трение, деформация стоп, твёрдость контакта, сопротивление движению | Условные |
| Отношение геометрических углов к PWM-углам и offsets | Не откалибровано для экземпляра робота |
| Точная позиция центра тяжести и высота корпуса | Не измерены |

**Поэтому:** ни смещение в миллиметрах, ни запас момента, ни количество падений в MuJoCo пока нельзя интерпретировать как показатели физического Freenove.

## Проверки

```bash
python -m hexlab.mujoco_model
python -m unittest discover -s tests -v
python -m hexlab.mujoco_experiment --mode stand --seconds 2 --out results/mujoco_geometry_corrected_stand_2s.json
python -m hexlab.mujoco_experiment --mode tripod --seconds 4 --out results/mujoco_geometry_corrected_tripod_4s.json
```

Примечание: базовый контроллер tripod по-прежнему экспериментальный — исправление геометрии **не означает**, что робот научился ходить.
