# Wheelbot V2 — офлайн-физика без визуального CAD

**Статус:** реальный эксперимент MuJoCo на *приближённой* контактной модели, только для исследования и тестирования автоматического replay pipeline. Это НЕ верифицированный оригинальный CAD и НЕ цифровой двойник Mini Wheelbot.

## Результат 7 ноября 2026

В текущей Python 3.13.5/Linux среде запущен MuJoCo 3.14.0 из проверенного офлайн-бандла Google Drive. Для каждого из двух сценариев выполнено 8000 шагов при dt=1 мс. Исходные состояния `qpos/qvel`, контакты, время и команды сохранены в трассах.

| Условие | Мин. наклон | Конечный наклон | Удержание в пределах 10° | Максимальная скорость | Проникновение |
|---|---:|---:|---:|---:|---:|
| Импульс источника, ограниченный условным моторным потолком | 0,257° | 90,009° | 0,015 с | 887,486 рад/с | 9,670 мм |
| Пассивное состояние | 90,000° | 90,008° | 0 с | 0,019 рад/с | 2,693 мм |

В **обоих** опытах не получилось устойчиво встать. Нет предупреждений численной неустойчивости. Сильное контактное проникновение подчёркивает, что контактная физика не откалибрована. Минимальный наклон 0,257° — лишь кратковременный проход через вертикаль, а не успех управления.

Проектные инерции и параметры взяты из [Mini-Wheelbot source commit](https://github.com/wheelbot/Mini-Wheelbot/tree/73815e49371c5fb5f49eec59d364e4d9d1b57b10), STEP-оси и схема открытого импульса сверены с [исследованием PR #86](https://github.com/Dmitry-dev-pet/alfred-hexapod-lab/pull/86). Оригинальные CAD/STL, которые в PR #86 являются *визуальными* (не контактными), **исключены** из этой облегчённой модели. Геометрия столкновений, положение центра масс и моторный предел по-прежнему являются допущениями.

**Сравнение с PR #86:** численные результаты не полностью совпали с ранее опубликованным прогоном (например, min tilt 0,111° и penetration около 2,17 мм). Пока не установлена причина несовпадения, нельзя называть эти прогоны физически эквивалентными. Нужен отдельный audit исходного собранного MJCF.

## Одна команда

```bash
python scripts/replay_pipeline.py run \
  experiments/replay-pipeline/wheelbot-offline-proxy-20261107.json
```

На Python 3.13 должна быть установлена MuJoCo 3.14.0 и NumPy; исходные STEP/STL скачивать **не требуется**, так как это только контактный proxy. Команда запускает настоящую физику, проверяет `qpos` и SHA-256 raw trace, создаёт новый JSON и отдельную страницу из существующего Wheelbot-шаблона и регистрирует запись **только в локальной рабочей копии**.

В данном задании `publish_policy=review_only`: **`--publish` запрещён**, пока не проверены визуальная геометрия, корректность контактов и поведение плеера. Никакого переноса в основную библиотеку Android, изменения `main` или merge.
