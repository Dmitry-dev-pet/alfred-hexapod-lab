# OpenBeni: первая проверка баланса и вставания, 2026-11-09

Готовая авторская политика удерживает стойку и поднимается из пяти проверенных
лежачих стартов. Это результат **исходной упрощённой модели**, а не проверка
настоящего робота или доказательство надёжности для произвольного падения.

Источник: [Mondo-Robotics/open-beni](https://github.com/Mondo-Robotics/open-beni),
commit `4545b86a131d05519050df11a424368ef9f06b4f`, MIT. Взяты оригинальные OBJ,
MJCF, массы/инерции, параметры приводов, пружин и готовый `policy.onnx`.
Никакого обучения или изменения весов. Запуск: Truthrail #333.

## Измеренный результат

В каждой активной серии: стойка, живот, спина, левый/правый бок и перевёрнутая
поза. Ещё пять пассивных контролей проведены при исходных контактах.
Всего 17 основных записей, 88 750 физических шагов и 8 892 кадров replay.
Две дополнительные проверки воспроизводимости сохранены отдельно.

| Старт | Подъём при исходном контакте | Начало секунды стойки при контакте 5 мс | Финальные 2 с спокойной стойки, 5 мс |
|---|---|---:|---|
| Стойка | удержана | 0,01 с | да |
| Живот | да | 0,43 с | да |
| Спина | да | 0,23 с | да |
| Левый бок | да | 0,91 с | да |
| Правый бок | да | 1,50 с | да |
| Вверх колёсами | да | 1,04 с | нет: остаточное движение |

Время считается **после включения управления**. Чтобы подтвердить подъём,
после указанного начала наблюдается полная непрерывная секунда опоры.
Наблюдение — 100 Гц. Перед лежачими стартами — 0,5 с пассивного успокоения;
фактические наклоны в момент включения сохранены. Поведение из первоначально
заданного бока не следует считать подъёмом без промежуточного перекатывания.
Во всех пяти пассивных контролях подъёма нет.

Стойка: оба колеса нагружены, суммарно не менее 70% веса, корпус не опирается
на пол, наклон <20°, высота в пределах 25 мм от авторской опоры, суставы около
авторской стойки, угловая скорость <2 рад/с. Спокойная стойка дополнительно
требует скорости <0,1 м/с и угловой скорости <1 рад/с все последние 2 с.

## Контактные ограничения

Авторские столкновения — коробки и цилиндры, визуальные меши не участвуют
в контакте. Максимум проникновения в пол в исходной серии — **20,515 мм**
(левый бок). Поэтому исходная серия не считается геометрически достоверным
подтверждением подъёма. Отдельная чувствительность уменьшает только время
контакта `geom_solref[:,0]` с 20 до 5 мс; геометрия, массы, политика и пределы
моментов сохранены. Подъём сохраняется, но проникновение остаётся до
**3,295 мм**, а столкновения по-прежнему упрощены. Это исследовательская
чувствительность, не калибровка пола или оборудования и не подобранное
доказательство точной механики. Геометрия оригинальных поверхностей и
пределы конкретных физических приводов отдельно не проверялись.

Масса опубликованной модели — 1,677225239 кг. Она не объявляется измеренной
массой комплектного продаваемого Beni. Приводы и пружины взяты из источника;
модель использует постоянные ограничения момента без нашей аппаратной
идентификации моторной характеристики.

## Воспроизведение

Python 3.12; MuJoCo 3.11.0 соответствует upstream lock, ONNX Runtime 1.23.2,
NumPy 2.5.4. Для PNG нужны Pillow и EGL. Node 24 используется только для
сверки с оригинальным JavaScript и проверки загрузчика.

```bash
git clone https://github.com/Mondo-Robotics/open-beni.git ../open-beni
git -C ../open-beni checkout 4545b86a131d05519050df11a424368ef9f06b4f
python research/openbeni/evaluate.py --upstream ../open-beni --out ../beni-results-audited --idle-controls
python research/openbeni/evaluate.py --upstream ../open-beni --out ../beni-results-stiff --contact-timeconstant .005
OPENBENI_SOURCE=$(realpath ../open-beni) python -m unittest discover -s research/openbeni -p 'test_*.py' -v
python research/openbeni/build_player.py
python research/openbeni/export.py --inputs ../beni-results-audited ../beni-results-stiff --out docs/hexapod/openbeni-recovery-v1
```

Адаптер повторяет браузерный контроллер автора: 40 наблюдений, GRU 512,
7 действий, 100 Гц политики, 500 Гц физики, задержка команды 4 мс и
авторское увеличение демпфирования коленей на 20%. Это CPU-перенос
браузерного режима на плоский пол с трением 1,0, **не запуск полного
mjlab training environment**. Крутящий момент заново вычисляется на каждом
физическом подшаге. Никаких внешних сил, восстановления позы, смены root
или автоматического сброса после начала физического эпизода нет.

## Проверки и replay

Четыре локальных теста проходят, включая побитовое совпадение наблюдений
с настоящим JavaScript-методом и сверку 96 случаев расчёта момента с
авторской реализацией. Повторы спины и левого бока при контакте 5 мс
совпадают побайтово. Во всех 17 основных записях нет предупреждений MuJoCo
или нечисловых состояний. Оригинальные восемь визуальных мешей экспортированы
с измеренными геометрическими позами, без обратной кинематики в браузере.
Загрузчик проверяет все 17 записей, исходные хеши, число/порядок кадров,
кватернионы; повреждённый хеш и небезопасный путь отвергаются.

Использован существующий многофайловый EN01-renderer с новым rig-адаптером.
Review-only pipeline закреплён на `c07e90cb46ab7c024bdaaf5129045bab1bd77b7c`:
локальная регистрация идемпотентна, `--publish` отвергается. Пример задания —
`replay-job.json`; готовые данные и локальный каталог хранятся в архиве.
Большие mesh/replay/ONNX-файлы не добавляются в Git. Страница рассчитана на
готовые данные из архива. Рабочая ветка плеера и Site этим PR не изменяются.

Нативный EGL-рендер исходных мешей проверен. Проверка браузерного интерфейса
заблокирована средой: Chromium завершился при `socket() ... EPERM`.
WebGL в браузере и реальное Android-управление не объявляются проверенными.
Независимый CI для этих optional research fixtures не заявлен.
