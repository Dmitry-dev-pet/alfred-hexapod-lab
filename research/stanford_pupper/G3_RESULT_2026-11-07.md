# G3 — физическая проверка обученного Pupper: G2 против Stanford и нулевого контроллера

**Вердикт:** G2 **ещё не обеспечивает управляемую ходьбу** в независимой MuJoCo CPU-реконструкции Stanford deploy-контроллера. Сохранение обучения PPO, экспорт JSON и отсутствие падений сами по себе не означают, что робот выполняет заданные скорости и направления. Исходная предобученная Stanford-политика лучше отслеживает большинство тестовых команд, но не является безошибочной (перерегулирование поворота, одно падение при переключении команд).

## Что реально проверено

- 30 завершённых физических MuJoCo-прогонов: **10 одинаковых сценариев × 3 контроллера**.
- 7 **controlled** сценариев: нейтральная стойка, вперёд, назад, боком, поворот, диагональ, переключение во время шага. Heading hold выключен; **фактически поданные командные значения vx/vy/wz побитово одинаковы** во всех трёх вариантах каждого сценария (зафиксировано проверкой в исследовательском скрипте).
- 3 дополнительных **native / deployment-style**: вперёд, назад, переключение команд. Использован родной heading hold каждой политики; **эти поданные yaw-команды уже могут различаться**, поэтому не трактовать результат как контролируемое сравнение одной и той же внутренней команды.
- Источники: \`cs123-stanford/pupper-mjlab@aa475e9a393a209b29fd5de7e0ee10f3de643230\`; оригинальный MJCF Git blob \`7771e176c42b3aed1d48cc62434771b0fceb7c8c\`. Визуальные 13 mesh геометрий с нулевой плотностью удалены, исходные массы/инерции/контактные сферы ступней сохранены. MuJoCo 3.14.0 CPU, Newtonian \`mj_step\` со свободным корпусом, 250 Гц физики, 50 Гц нейросети, 4 physics-step задержки положения сервоприводов, \`kp=5.5/kd=0.25\`, момент до 3 Н·м. Условия — плоский пол, одинаковые стартовые qpos и нейтральная выдержка 1 с, затем плавное включение команды.
- G2 — именно сохранённый экспорт \`policy.json\` **после G2 128-итерационного обучения** (не checkpoint model_96); SHA256 \`228c70944c26e697cb93f42325386a47d20713699c22fb8bc24ca9fb9728562c\`, извлечён из проверенного приватного G2 GitHub artifact. Original Stanford \`default_policy.json\`, SHA256 \`ecf3a4ab8ea392dccda64977faa29d813dadc0d6099ae3abff5f84cc57156712\`, получен из закреплённого upstream deploy-репозитория. Нулевой контроллер — **0 дополнений к 12 нейтральным суставным позициям**, те же серво и физика.
- Контракты JSON: обе версии v2, \`obs_spec\` одинаковый 20×48=960, сети одинаковых форм 960→256→128→128→128→12, одинаковые суставы и servo gain. **Важные различия:** \`command_clip.vx\` ±0.7 у G2 против ±1.5 у Stanford; heading-hold \`kp=1/clip=.3\` против \`1.5/1.0\`; \`gallop_speed=1000\` у G2 против 0.5 у Stanford; в G2 отсутствуют \`lift_table\` и \`jump_slot\`. Двух неиспользуемых полей caps из оригинальной схемы достаточно для выполнения старого CPU evaluator без прыжка/бега; G2 нейровеса, observation и gait reference **не подменялись**.

## Измеренные результаты

**Controlled** (без heading hold; 7 сценариев, значения продвижения в мировой системе, yaw — накопленный угол):

| Команда | Stanford | G2 | Zero |
|---|---|---|---|
| Стоять: дрейф за 7 с | 0.002 м | **0.108 м** | 0.0075 м |
| Вперёд +0.20 м/с: ΔX | **+1.088 м** | +0.117 м | −0.007 м |
| Вперёд +0.20 м/с: yaw | −65.8° | **−417.6°** | 0° |
| Назад −0.12 м/с: ΔX | −0.735 м | −0.113 м | −0.007 м |
| Боком +0.12 м/с: ΔY | +0.436 м | +0.011 м | 0 м |
| Поворот +0.20 рад/с: yaw | +222.9° | +2.2° | 0° |
| Диагональ: ΔX / ΔY | +0.962 / −0.188 м | +0.353 / −0.425 м | −0.007 / 0 м |
| Переключение: ΔX | +0.571 м | −0.057 м | −0.007 м |

Поворот +0.20 рад/с в течение ~7 с предполагает ≈80°; Stanford **сильно превышает** этот угол, и её не следует считать точным контроллером yaw, хотя G2 здесь почти не поворачивает.

**Native heading hold** (три других прогона):

| Показатель | Stanford | G2 | Zero |
|---|---:|---:|---:|
| Вперёд +0.20 м/с, world ΔX | +1.322 м | +0.383 м | −0.007 м |
| Вперёд, итоговый yaw | −13.8° | **−431.8°** | 0° |
| Вперёд, XY RMSE body frame | 0.0783 м/с | **0.1474 м/с** | 0.1413 м/с |
| Вперёд, число physics ticks в torque saturation | 0.0444% | **5.78%** | 0% |
| Вперёд, минимум высоты root | 0.152 м | **0.105 м** | 0.155 м |
| Назад −0.12 м/с, world ΔX | −0.547 м | −0.114 м | −0.007 м |
| Переключение: падение (physics ticks) | 443 | **0** | 0 |

В G2 при стоянии лишь ≈45.4% из записанных 20-мс кадров показывали минимум две стопы, нагруженные более 0.2 Н; у Stanford — ≈99.1%. Это **частный Fz proxy**, не медицинская/аппаратная квалификация и не эквивалент строгого многоугольника опоры. Вперед G2 также показала torque saturation 5.78% физических тиков против 0.0444% у оригинала.

**Итог по падениям:** 0/10 G2, 1/10 Stanford, 0/10 zero. Единственное падение Stanford — сценарий \`native switch\`, 443 физических тика fall-guard, максимальный tilt ~178.5°, root z пересёк уровень пола. После падения пройденное расстояние не считать успехом. Отсутствие падений G2 — не доказательство ходьбы: нулевая политика тоже не падала и почти не двигалась.

## Достоверность и ограничения

- Все 30 полных покадровых JSON с реальными MuJoCo \`qpos\`, командами, контактными \`foot_Fz\`, углами наклона и моментами приводов имеют отдельные SHA-256; перепроверены на Mac и в независимой среде по полученному GitHub ZIP.
- Выборка **детерминированная, один исходный эпизод на сценарий**: это не 30 независимых случайных seeds, не статистическая оценка надёжности.
- Это воспроизведённая **Stanford deploy-JSON CPU physics**, а не native \`MJLab\` тренинг-симулятор или битовая проверка нейросети против C++ контроллера. Реальный Pupper и его сервоприводы не подключались. Модель неполна по геометрии и оценке столкновений корпуса.
- Не тестировали способность G2 прыгать/бегать: её экспорт не содержит \`jump_slot\`/lift/gallop-contract исходного контроллера. Не присваивать ей возможности оригинальной модели.
- Слабые показатели G2 могут быть связаны с **недостаточным обучением** (128 PPO итераций против тысяч в Stanford notebook), выбором шести reward weights, динамикой контроллера в независимой CPU-модели и/или **непроверенной паритетностью экспортированных JSON действий с native MJLab RSL-RL**. Нельзя пока выбирать единственную причину.
