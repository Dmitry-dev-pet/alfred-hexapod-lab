## Что реально сделано

Воспроизведён пятсекундный **физический** эксперимент в MuJoCo 3.14.0 CPU, без CUDA, нейросети, RL, готовой походки и ручной покадровой анимации:

- Исходный Pupper v3 MJCF взят из [cs123-stanford/pupper-mjlab](https://github.com/cs123-stanford/pupper-mjlab) @ `aa475e9a393a209b29fd5de7e0ee10f3de643230`.
- Точное совпадение Git blob SHA-1 исходного XML: `7771e176c42b3aed1d48cc62434771b0fceb7c8c` (9 711 байт). Копия: [upstream/pupper_v3.xml](upstream/pupper_v3.xml); текст открытого исходника сохранён с оригинальной [Apache-2.0 лицензией](upstream/LICENSE). **13 STL-мешей в наш GitHub не копировались.**
- Для физического теста удалены только 13 нулевых по плотности и неконтактных визуальных мешей; все исходные массы, тензоры инерции, суставы, ограничения, 8 сфер коллизий и 4 foot-site сохранены.
- Добавлены плоский пол и 12 позиционных приводов с параметрами Stanford: `kp=5.5`, `kd=0.25`, `force_limit=±3 Н·м`. Физика — `dt=0.004 с`, 2 итерации solver, 50 Гц частота сохраняемых данных. Стойка: 12 исходных углов `DEFAULT_POSE`, начальная высота 0.18 м. **Задержки приводов/sensor noise из полного mjlab здесь не воспроизводятся.**
- Действительно вызван `mujoco.mj_step` 1 250 раз; записаны `qpos`, угол/позиция корпуса, действительные силы контактов стопы и силы актуаторов, 250 кадров.
- 4/4 локальных теста PASS, в т. ч. проверка контрольной суммы XML, 12 DOF/3.17 кг, коллизий и **точное совпадение двух независимых 1-секундных опытов**.

## Повторить в Linux/macOS без GPU

Нужен Python с доступным MuJoCo 3.14.0. В папке репозитория:

```bash
python -m pip install "mujoco==3.14.0" numpy
python -m unittest discover -s research/stanford_pupper -p 'test_*.py' -v
python research/stanford_pupper/reproduce_pupper.py \
  --source-xml research/stanford_pupper/upstream/pupper_v3.xml \
  --seconds 5 \
  --output /tmp/pupper_stance_5s.json
```

Фиксация исходных файлов, среды, численных опций и последовательности `mj_step` делает эксперимент воспроизводимым. Последние десятичные разряды не гарантированы бит-в-бит между платформами/версиями MuJoCo.

## Что сознательно НЕ сделано

1. Не использована готовая нейросеть. [Stanford deploy](https://github.com/cs123-stanford/pupper_gait_deploy/tree/70df56dd47e98195b7d51fe7ff7194a2581b0e0d/policies) публикует `default_policy.json` (Git blob `27f8a94b95c0e960b01b0cd7b88c5cd9ab249b3c`), однако это **контракт развёртывания** для neural_controller, а не напрямую загружаемый в `mjlab play` checkpoint.
2. Для верного воспроизведения сети нужно проверить `in_shape`, порядок 12 суставов, `obs_spec`, историю 20×36, нормализацию, преобразование действий, фазу и сенсорную/приводную задержку; затем реализовать независимый CPU-inference и провести сравнение с upstream C++/PyTorch.
3. Не обучались сети и не изменялись параметры XGO-Lite3; физические модели разных роботов пока не смешивались.
4. Не опубликованы новые кадры в Android-плеере: для полноценных оригинальных визуальных STL нужны отдельные лицензированные локальные ассеты.
