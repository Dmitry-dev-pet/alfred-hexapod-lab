# Stanford Pupper v3 — Apple M4 CPU vs MPS PPO, 7 ноября 2026

**Статус:** оба обучения и проверки checkpoint завершились. Это **не** успешное освоение ходьбы.

- Исходники: [PR #76](https://github.com/Dmitry-dev-pet/alfred-hexapod-lab/pull/76), зафиксированный commit `6d22db2a119fb9cf7fb2cab180bd748d7830b445`.
- Выполнение: [GitHub Actions run 42382356713](https://github.com/Dmytry-lab/runner-smoke/actions/runs/42382356713), существующий раннер `mac-m4-org-01`; изолированный непривилегированный macOS/ARM64 исполнитель.
- Обучение: независимый SB3 PPO/Gymnasium baseline (не штатное Stanford MJLab); исходная физика Stanford Pupper на CPU MuJoCo 3.14.0, 4 Gymnasium-среды, seed `20261107`, профиль награды `tracking`, одинаковые параметры PPO.
- Запрошено 100 000 шагов на устройство; фактически по 100 352 шага из-за округления до PPO rollout-блоков.
- Архив двух чекпойнтов, оценок и логов: GitHub Artifact ID `13578152307`, SHA-256 ZIP `59aeb0867d8f726ebcbce7e31305dd247ed822d68fd5583d82e8db7e3baab61d`.
- Точность checkpoint подтверждена хешами в `receipt.json`, физика оценки — реальные `mj_step` и сохранённые кадры MuJoCo.

**Интерпретация:** падений по заданному guard-порогy не было, но это не устойчивая походка. Обе модели практически стоят, приседают до ~8.5 см и на подавляющем большинстве кадров держат только две нагруженные стопы; ошибки отслеживания команд хуже нулевой политики. Частота кадров оценки 25 Гц, контактами считали силы >0.2 N.
