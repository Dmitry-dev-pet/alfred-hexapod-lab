# EN01 v5 — repaired folding guards and CAD self contact

The impossible folding reported by the user is prevented in this revised
simulation. Both hip coordinates stay inside the declared operating range in
every physics step of nine completed cases. An independent check of the original
73-part triangle meshes finds no unexpected intersection in 2,700 saved poses or
8,073 additional interpolated playback poses. Intended joint mating groups are
excluded, as documented in `contact_mesh_audit.py`.

## Mechanical changes

The old diagnostic range -0.22..0.65 rad allowed the calf through the side plate,
floor plate and battery. v5 uses **conservative operating guards 0..0.65 rad**
relative to the source CAD assembly, with a 0.01-rad activation margin. This
deliberately reserves travel before the known interference at -0.04 rad. A
651-pose sweep at 0.001-rad intervals found no unexpected triangle-surface
intersection. Discrete sampling is not continuous certification, and these
bounds are **not measured factory stops**.

Twenty-eight original structural CAD parts now provide convex outer-envelope
self-contact shapes, with 0.25-mm contact margins. They are conservative proxies:
their filled cavities can make contact earlier than the original concave solid.
Original meshes remain unchanged for visualization and independent checking.
The separate floor proxies and measured tire cylinder are preserved. Hip limit
and self-contact response use direct stiffness/damping parameters instead of
the previous permissive limit response; timestep is 0.25 ms. Parent/joint mating
exclusions are explicit, including fixed-base tests. Rod/calf is a loop joint;
rod/upper conservative hull contact is excluded because the hull fills link
holes, while their actual triangle surfaces remain checked independently.

Explicit body inertias preserve the previous assumed 0.322-kg mass and every
body's inertia, COM and inertia orientation. Gravity, 0.14709975-Nm hip ceiling,
assumed motor speed derating and 0.030-Nm wheel ceiling are unchanged. No lift
force, pose projection, replay angle clamp or altered animation is applied.

The encoder/CAD zero remains unmeasured. Source height 38 is assigned **q=0.1 rad
as a declared working hypothesis**, keeping the source jump targets
0.641495/0.643029 rad inside the operating range. The previous battery used
different anchor hypotheses. Accordingly, the new jump result is not an isolated
measurement of how much benefit came from the contact change: anchor, timestep,
guards and contacts all differ from v4.

## Measured simulations

Each case runs six seconds. Eight use 24,000 CPU MuJoCo 3.14.0 steps; a refinement
case uses 48,000 steps at 0.125 ms. All save 300 genuine qpos/qvel/body-pose/contact
frames, with all-step hip extrema, contact counts, closure error and jump gates.

| Case | Observation |
| --- | --- |
| Stand | Upright for 6 s; maximum x drift 3.28 cm |
| Crouch | Remains upright; hips reach about 0.01085 rad |
| Forced folding | Continuous saturated servo demand cannot collapse the leg into the chassis; minimum hip coordinate about 0.00740 rad |
| Forced extension | Upper guard holds; uncontrolled extension tips the robot over |
| Source jump, 1-ms loop | No qualified flight |
| Source jump, 2-ms loop | No qualified flight |
| Source jump, 5-ms loop | 9.804-mm wheel clearance, 75.75-ms qualified upward flight, 3.193-s clean upright support after landing |
| Source jump, 10-ms loop | Falls; brief airborne intervals do not qualify as an upward supported jump |
| Source jump, 5-ms loop, half timestep | 9.770-mm clearance, 75.625-ms flight, 3.210-s stable support |

All-step self-proxy penetration is zero in these cases; margins allow forces
before geometric overlap. A separate fixed-base, no-floor, no-gravity unit test
applies the full continuous actuator torque for three seconds in each direction
without changing qpos after a physics step. Hip extrema remain approximately
0.00724..0.64880 rad, and measured self-contact force is nonzero. Joint closure
remains compliant rather than mathematically rigid; per-case residuals are in
`contact_v5_results.json`. Soft floor contact, including impact penetration,
remains an uncalibrated part of the surrogate.

The five-millisecond clock and absolute servo zero are hypotheses. The numerical
jump/landing pass **does not establish that a real EN01 will jump this way**.
Mass distribution, spring behavior, loaded servo response and floor compliance
still require calibration.

## Verification and replay

The entire 240,000-step battery was repeated. All 21 dataset members, including
raw traces, compact replays, models and results, reproduce byte-for-byte. Export
independently rebuilds every saved qpos through MuJoCo FK with zero pose residual.
The actual Three.js math checks 197,100 original part transforms with maximum
residual 4.44e-16 m. Additional quarter/mid/three-quarter playback states were
checked using the same per-body position interpolation and quaternion slerp.
This is numerical verification; cloud-browser WebGL rendering is not claimed.

Six new focused tests pass, including saturated torque stop response, unchanged
inertias, detection of the old self-intersecting v4 pose, forged-pose rejection
and source command timing under physics substeps. Eight existing original-jump
tests also pass, including the actual compiled pinned C++ command comparison.

The existing replay pipeline packages nine immutable review records, preserves
all 66 source catalog entries, is idempotent and refuses publication from the
research branch. A separate authorized player publication uses these same
verified replay bytes. No MP4/GIF, remote runner or hardware purchase.

Reproduce with the pinned external original mesh:

```bash
python -m research.navbot_en01.contact_battery --out /path/fresh-dataset --cad-mesh /path/original-meshes.json
python scripts/package_en01_contact.py --dataset /path/fresh-dataset --catalog /path/library.json --out /path/fresh-review
```

CAD-containing MJCF and raw traces are external assets; source and compact
