# EN01 v0 versus CAD nominal-pose surrogate v1: independent CPU replay

Date: 2026-11-09. **DIAGNOSTIC ONLY, not validated linkage or sim-to-real**.

This compares unchanged v0 and a separate v1 surrogate built from the pinned STEP assembly placements. Four-bar kinematics, servo shaft zeros, part masses/inertias, exact current motor SKU and torque-speed curves are unknown. No physical hardware was tested.

## Interpretation

- v0 reproduces the historical 2026-11-08 receipt to two decimal places (33.8 / 38.7 cm and both jump failures), cross-checking the local physics harness.
- v1 has lower stand drift (11.27 versus 33.80 cm) but worse crouch drift (63.68 versus 38.68 cm); fast jump travels over 2 m during a fall. **No jump succeeds.**
- v1 uses CAD-measured *nominal placement*, not the actual articulated four-bar linkage. It is a **surrogate**, not CAD-accurate kinematics; its improved stand metric does not validate hardware.
- No Android replay publication, no MP4/GIF, no merge into main, no hardware purchase.

## Reproduction

Run the versioned generator with: python research/navbot_en01/cad_pose_v1.py

Then use the existing probe: python research/navbot_en01/probe.py --model research/navbot_en01/model_v1_cad_pose.xml --mode stand --duration 6 --out .cache/en01_v1_stand.json

Repeat for crouch, jump and jump_fast; omit --model to run original v0. The eight numbers above were generated by a separate local script (physics_compare.py) implementing the identical PD control equations and recorded in this chat's local research bundle. The new --model option was added in this PR after that independent comparison and still requires its own additional run-level verification.
